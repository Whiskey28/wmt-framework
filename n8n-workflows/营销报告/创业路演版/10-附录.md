### 核心技术栈

#### 1. n8n工作流引擎

**版本**：n8n 2.4+

**用途**：自动化流程编排

**关键节点**：
- Webhook节点：接收用户提交
- Code节点：数据验证和科学计算
- HTTP Request节点：调用DeepSeek AI API
- Write Binary File节点：生成报告文件
- Email Send节点：发送邮件

#### 2. DeepSeek AI

**模型**：deepseek-chat

**API**：https://api.deepseek.com/v1/chat/completions

**关键参数**：
- temperature：0.7-0.8
- max_tokens：4000-8000
- system prompt：精心设计的提示词

#### 3. MySQL数据库

**版本**：MySQL 8.0+

**表结构**：
- health_form_submissions：用户提交数据
- 字段：submission_id, age, gender, height, weight, goal_type, goal_value, goal_time, daily_time, kitchen_condition, facility, experience, email, status, created_at

#### 4. 文件系统

**存储格式**：
- HTML：美观的网页格式
- Markdown：便于阅读和编辑
- JSON：结构化数据

**存储路径**：./outputs/health/

#### 5. SMTP邮件服务

- 发送HTML格式邮件

### 科学计算公式

#### 1. BMI计算

```
BMI = 体重(kg) / (身高(m))²
```

#### 2. BMR计算（Harris-Benedict公式）

**男性**：
```
BMR = 88.362 + (13.397 × 体重) + (4.799 × 身高) - (5.677 × 年龄)
```

**女性**：
```
BMR = 447.593 + (9.247 × 体重) + (3.098 × 身高) - (4.330 × 年龄)
```

#### 3. TDEE计算

```
TDEE = BMR × 活动系数
```

**活动系数**：
- 久坐（很少运动）：1.2
- 轻度活动（每周1-3次）：1.375
- 中度活动（每周3-5次）：1.55
- 高度活动（每周6-7次）：1.725
- 极高活动（每天2次以上）：1.9

#### 4. 营养素分配

**蛋白质**：
- 增肌：体重 × 2.0g
- 减肥：体重 × 1.4g
- 维持：体重 × 1.0g

**脂肪**：
- 目标热量的25%

**碳水化合物**：
- (目标热量 - 蛋白质热量 - 脂肪热量) / 4
