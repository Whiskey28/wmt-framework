# 糖尿病饮食分析表单 - 使用说明

## 📋 功能概述

这是一个用于**糖尿病饮食分析AI Agent**的前端表单页面，用户可以通过填写表单来提交饮食分析请求。

## 🎯 表单功能

### 1. 用餐信息
- **用餐时间**：选择具体的用餐时间（必填）
- **食物列表**：动态添加多个食物，每个食物包含：
  - 食物名称（必填）：如"米饭"、"青菜"、"鸡蛋"
  - 数量（必填）：如"1碗"、"200g"、"2个"

### 2. 用户信息
- **邮箱**（可选）：填写后报告将自动发送到邮箱
- **是否糖尿病患者**（必填）：选择是/否
- **糖尿病类型**（当选择"是"时显示）：
  - 1型糖尿病
  - 2型糖尿病
  - 妊娠期糖尿病
- **当前用药**（当选择"是"时显示）：
  - 胰岛素
  - 口服药
  - 无
- **年龄**（可选）
- **性别**（可选）
- **身高**（可选，单位：cm）
- **体重**（可选，单位：kg）

## 🚀 使用方法

### 1. 配置Webhook URL

打开 `糖尿病饮食分析表单.html` 文件，找到以下代码：

```javascript
const webhookUrl = 'https://your-n8n-instance.com/webhook/diabetes-analysis';
```

将 `https://your-n8n-instance.com/webhook/diabetes-analysis` 替换为您的实际n8n webhook URL。

**如何获取webhook URL：**
1. 在n8n中打开"糖尿病饮食分析AI Agent"工作流
2. 找到"处理糖尿病分析请求"节点（Webhook节点）
3. 点击节点，查看webhook URL
4. 格式通常为：`https://your-n8n-domain.com/webhook/diabetes-analysis`

### 2. 部署表单

#### 方式一：直接打开HTML文件
- 双击 `糖尿病饮食分析表单.html` 文件
- 在浏览器中打开
- **注意**：由于CORS限制，可能需要配置本地服务器

#### 方式二：使用本地服务器（推荐）

**使用Python：**
```bash
# Python 3
python -m http.server 8000

# 然后访问：http://localhost:8000/糖尿病饮食分析表单.html
```

**使用Node.js：**
```bash
# 安装http-server
npm install -g http-server

# 运行
http-server

# 然后访问：http://localhost:8080/糖尿病饮食分析表单.html
```

#### 方式三：部署到Web服务器
- 将HTML文件上传到您的Web服务器
- 通过浏览器访问URL

### 3. 使用表单

1. **填写用餐信息**：
   - 选择用餐时间
   - 添加食物（点击"+ 添加食物"按钮）
   - 填写食物名称和数量

2. **填写用户信息**：
   - 选择是否糖尿病患者
   - 如果是，填写糖尿病类型和用药情况
   - 可选填写其他信息（年龄、性别、身高、体重）
   - 可选填写邮箱（用于接收报告）

3. **提交分析**：
   - 点击"提交分析"按钮
   - 等待分析完成（通常需要3-5分钟）
   - 如果填写了邮箱，报告将自动发送到邮箱
   - 页面会显示提交结果

## 🔧 自定义配置

在HTML文件的 `<script>` 部分，可以修改：

```javascript
// 当前设置为当前时间，可以修改为其他时间
const now = new Date();
now.setMinutes(now.getMinutes() - now.getTimezoneOffset());
document.getElementById('mealTime').value = now.toISOString().slice(0, 16);
```

2. **默认食物项数量**：

```javascript
// 默认添加1个食物项，可以修改
window.onload = function() {

    // ...

```

## ⚠️ 注意事项

1. **CORS问题**：
   - 如果直接打开HTML文件，可能会遇到CORS跨域问题
   - 建议使用本地服务器或部署到Web服务器

2. **Webhook URL配置**：
   - 确保webhook URL正确
   - 确保n8n工作流已激活
   - 确保网络可以访问n8n实例

3. **数据验证**：
   - 表单会进行基本验证
   - 后端（n8n工作流）会进行更严格的验证
   - 如果验证失败，会显示错误信息

4. **邮箱功能**：
   - 邮箱是可选的
   - 如果填写邮箱，报告会发送到邮箱
   - 如果不填写邮箱，只能通过API响应获取结果

## 🐛 故障排除

### 问题1：提交后显示"网络错误"
- **原因**：webhook URL配置错误或无法访问
- **解决**：检查webhook URL是否正确，确保n8n工作流已激活

### 问题2：提交后显示"数据验证失败"
- **原因**：必填字段未填写或格式错误
- **解决**：检查所有必填字段是否已填写，食物列表是否至少有一项

### 问题3：没有收到邮件
- **原因**：邮箱填写错误或n8n邮件服务配置问题
- **解决**：检查邮箱地址是否正确，检查n8n的SMTP配置

### 问题4：页面无法打开
- **原因**：文件路径错误或浏览器不支持
- **解决**：使用现代浏览器（Chrome、Firefox、Edge等），确保文件路径正确
