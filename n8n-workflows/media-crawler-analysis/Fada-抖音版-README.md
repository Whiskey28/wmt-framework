# Fada抖音数据分析自动化工作流

基于 MediaCrawler 数据库的抖音内容智能分析、AI分类、数据统计和内容生成自动化工作流。

## 📖 项目简介

**Fada抖音** 是一个完整的 n8n 工作流系统，专注于抖音平台的内容数据分析。工作流从 MediaCrawler 数据库读取抖音数据，通过 AI 智能分类、数据清洗、统计分析，最终生成 HTML 报表和可发布的文章内容。

### 核心功能

- ✅ **动态关键词查询**：支持多关键词选择，动态生成 SQL 查询
- ✅ **数据验证与清洗**：自动识别并过滤无效数据，统一数据格式
- ✅ **AI 批量分类**：使用 DeepSeek AI 对内容进行智能分类（批量处理，高效省成本）
- ✅ **数据统计分析**：生成分类统计、Top10 热门内容榜单
- ✅ **HTML 报表生成**：自动生成美观的数据分析报告
- ✅ **AI 内容生成**：基于分析结果自动生成适合抖音发布的文章
- ✅ **内容保存**：自动保存 Markdown 和 JSON 格式的内容文件

## 🎯 适用场景

- 抖音内容趋势分析和监控
- 热点关键词数据挖掘
- 内容分类和标签化
- 数据驱动的运营决策
- 自动化内容创作

## 🏗️ 工作流架构

### 整体流程图

```
手动触发
  ↓
[关键词查询链路]

  ↓
[数据处理链路]
数据验证 → 过滤有效数据 → 数据清洗 → 准备批量分类 → AI批量分类 → 合并AI响应 → 解析批量分类结果
  ↓
[数据分析链路]
过滤低置信度 → 数据分组 → 计算Top10 → 统计分析
  ↓
[输出链路]
  ├─→ 生成报表 → 确保文件夹存在 → 保存报表 (HTML)
  └─→ 生成内容生成上下文 → 格式化内容生成提示词 → AI生成内容 → 格式化内容 → 发布准备
                                                                                    ↓
                                                                        ┌───────────┴───────────┐
                                                                        ↓                       ↓
                                                          保存内容（手动发布）     转换元数据为二进制 → 保存元数据
                                                              (Markdown)                          (JSON)
```

### 主要模块说明

#### 1. 关键词查询模块
- **抖音关键词列表**：查询数据库中所有可用的 `source_keyword`，供用户参考选择
- **工作流参数**：设置查询参数（关键词、时间范围、数量限制）
- **解析关键词参数**：解析并标准化参数
- **数据查询-SQL生成**：动态生成针对 `douyin_aweme` 表的 SQL 查询语句
- **数据库查询**：执行 SQL，获取原始数据

#### 2. 数据处理模块
- **数据验证**：验证数据完整性和有效性
- **过滤有效数据**：过滤掉验证失败的数据
- **数据清洗**：统一数字格式、时间戳格式，计算衍生指标
- **准备批量分类**：将数据分批，准备批量 AI 分类请求
- **AI批量分类**：调用 DeepSeek API 进行批量分类
- **合并AI响应**：将 AI 响应合并到原始数据
- **解析批量分类结果**：解析 AI 返回的分类结果，合并到每条数据

#### 3. 数据分析模块
- **过滤低置信度**：过滤掉分类置信度低于 0.6 的数据
- **数据分组**：按分类和平台分组数据
- **计算Top10**：计算每个分类的热门内容 Top10
- **统计分析**：生成全量数据统计信息

#### 4. 报表生成模块
- **生成报表**：生成 HTML 格式的数据分析报告
- **确保文件夹存在**：检查并提示创建输出文件夹
- **保存报表**：保存 HTML 报表到 `./outputs/report/` 目录

#### 5. 内容生成模块
- **生成内容生成上下文**：从统计分析结果中提取摘要、Top10、关键发现
- **格式化内容生成提示词**：构建 AI 内容生成的提示词
- **AI生成内容**：调用 DeepSeek API 生成文章内容
- **格式化内容**：提取标题、正文、标签
- **发布准备**：准备发布数据，转换为二进制格式
- **保存内容（手动发布）**：保存 Markdown 格式的文章到 `./content-to-publish/` 目录
- **转换元数据为二进制**：将元数据转换为二进制格式
- **保存元数据**：保存 JSON 格式的元数据到 `./content-to-publish/` 目录

## 📋 节点详细说明

### 关键节点配置

#### 1. 工作流参数（Set 节点）

**位置**：关键词查询模块

**配置字段**：
- `keywords_raw` (String)：关键词列表，用逗号分隔，例如：`论文,AI,毕业论文`
- `days` (Number)：查询最近 N 天的数据，默认：`7`
- `limit` (Number)：查询数量限制，默认：`1000`
- `useSourceKeyword` (Boolean)：是否使用 `source_keyword` 字段，默认：`true`

**示例配置**：
```json
{
  "keywords_raw": "毕业论文,论文,AI",
  "days": 180,
  "limit": 20,
  "useSourceKeyword": true
}
```

#### 2. 数据查询-SQL生成（Code 节点）

**功能**：根据工作流参数动态生成 SQL 查询语句

**输入**：来自 `解析关键词参数` 节点的配置

**输出**：
```json
{
  "sql": "SELECT ... FROM douyin_aweme ...",
  "config": { "keywords": [...], "days": 7, ... }
}
```

#### 3. AI批量分类（HTTP Request 节点）

**API 配置**：
- **URL**：`https://api.deepseek.com/v1/chat/completions`
- **Method**：`POST`
- **Authentication**：Bearer Token（需要配置 DeepSeek API Key）
- **Model**：`deepseek-chat`
- **Temperature**：`0.7`
- **Max Tokens**：`8000`

**批量处理配置**：
- **Batch Size**：`60`（每批处理 60 条数据）
- **优势**：大幅减少 API 调用次数，降低成本

#### 4. 生成报表（Code 节点）

**输出格式**：
- **JSON**：报表元数据（report_id, generated_at, total_count 等）
- **Binary**：HTML 格式的报表文件（base64 编码）

**报表内容**：
- 总体统计（总数据量、分类数量、平台数量）
- 分类统计（每个分类的数量、平均点赞、平均评论）
- Top10 热门内容（按分类展示）

#### 5. 发布准备（Code 节点）

**关键功能**：
- 将 `raw_content` 字符串转换为二进制格式（base64）
- 准备发布所需的元数据

**输出格式**：
```json
{
  "json": {
    "platform": "douyin",
    "title": "...",
    "content": "...",
    "raw_content": "...",
    "tags": [...],
    "publish_time": "...",
    "publish_data": {...}
  },
  "binary": {
    "raw_content": {
      "data": "base64编码的内容",
      "mimeType": "text/markdown",
      "fileName": "..."
    }
  }
}
```

## 🚀 快速开始

### 前置要求

1. **n8n 环境**
   - n8n 版本 >= 1.0.0
   - Node.js >= 16.0.0

2. **数据库**
   - MySQL 5.7+ 或 MySQL 8.0+
   - MediaCrawler 数据库（包含 `douyin_aweme` 表）

3. **AI 服务**
   - DeepSeek API Key
   - 足够的 API 调用配额

4. **文件系统**
   - 确保以下目录存在（或工作流会自动创建）：
     - `./outputs/report/`（报表输出目录）
     - `./content-to-publish/`（内容输出目录）

### 安装步骤

#### 1. 导入工作流

1. 打开 n8n
2. 点击 "Workflows" → "Import from File"
3. 选择 `workflow-templates/Fada-抖音版数据分析.json`
4. 导入后，工作流名称显示为 "Fada-抖音版数据分析"

#### 2. 配置数据库连接

1. 找到 **数据库查询** 节点
2. 点击节点，在 "Credentials" 中配置 MySQL 连接：
   - Host：数据库主机地址
   - Database：`media_crawler`
   - User：数据库用户名
   - Password：数据库密码
   - Port：`3306`（默认）

3. 同样配置 **抖音关键词列表** 节点的数据库连接

#### 3. 配置 AI API

1. 找到 **AI批量分类** 节点
2. 在 "Credentials" 中配置 DeepSeek API：
   - 选择 "HTTP Bearer Auth"
   - Token：你的 DeepSeek API Key

3. 同样配置 **AI生成内容** 节点的 API 连接

#### 4. 配置工作流参数

1. 找到 **工作流参数** 节点
2. 根据你的需求修改参数：
   - `keywords_raw`：要分析的关键词（例如：`论文,AI,毕业论文`）
   - `days`：查询最近多少天的数据（例如：`180` 表示最近 180 天）
   - `limit`：最多查询多少条数据（例如：`1000`）
   - `useSourceKeyword`：是否使用 `source_keyword` 字段（建议保持 `true`）

### 运行工作流

#### 方式1：手动触发

1. 点击工作流右上角的 "Execute Workflow" 按钮
2. 工作流会依次执行所有节点
3. 查看每个节点的输出，确认数据流正确

#### 方式2：定时触发（可选）

1. 将 **手动触发** 节点替换为 **Schedule Trigger** 节点
2. 配置触发频率（例如：每天凌晨 2 点）
3. 工作流会自动执行

### 查看结果

#### 1. HTML 报表

- **位置**：`./outputs/report/report_[timestamp].html`
- **内容**：包含总体统计、分类统计、Top10 热门内容
- **打开方式**：用浏览器打开 HTML 文件

#### 2. 生成的文章内容

- **Markdown 文件**：`./content-to-publish/douyin_[timestamp].md`
- **元数据文件**：`./content-to-publish/douyin_[timestamp].json`
- **内容**：适合在抖音发布的文章草稿

## 🔧 配置说明

### 关键词配置

#### 查看可用关键词

1. 单独执行 **抖音关键词列表** 节点
2. 查看输出，了解数据库中有哪些 `source_keyword`
3. 选择你想要分析的关键词

#### 设置关键词

在 **工作流参数** 节点中设置 `keywords_raw` 字段：

- **单个关键词**：`论文`
- **多个关键词**：`论文,AI,毕业论文,本科论文`
- **支持中文逗号**：`论文，AI，毕业论文`

### 时间范围配置

在 **工作流参数** 节点中设置 `days` 字段：

- **最近 7 天**：`7`（默认）
- **最近 30 天**：`30`
- **最近 180 天**：`180`
- **最近 365 天**：`365`

### AI 分类配置

#### 批量大小调整

在 **准备批量分类** 节点的代码中修改 `batchSize`：

```javascript
const config = {
  batchSize: 60,  // 修改这个值
  // ...
};
```

**建议值**：
- 小数据集（< 100 条）：`10-20`
- 中等数据集（100-500 条）：`30-60`
- 大数据集（> 500 条）：`60-100`

**注意**：批量大小受 AI API 的 token 限制影响，如果遇到 "token limit exceeded" 错误，需要减小 `batchSize`。

#### 置信度阈值

在 **过滤低置信度** 节点中修改阈值：

- 当前阈值：`0.6`
- 更严格：`0.7` 或 `0.8`
- 更宽松：`0.5` 或 `0.4`

### 内容生成配置

#### 修改生成风格

在 **生成内容生成上下文** 节点中修改 `style` 字段：

```javascript
style: '适合抖音的短视频口语化文案风格，轻松、有画面感，带一点故事性和互动感。'
```

可以改为：
- `专业学术风格`
- `幽默风趣风格`
- `简洁实用风格`

#### 修改字数要求

在 **生成内容生成上下文** 节点中修改 `word_limit` 字段：

```javascript
word_limit: '800-1200字'
```

可以改为：
- `500-800字`（短内容）
- `1200-2000字`（长内容）

## 🐛 故障排除

### 常见问题

#### 1. 数据库连接失败

**错误信息**：`Connection refused` 或 `Access denied`

**解决方案**：
- 检查数据库服务是否运行
- 验证数据库连接信息（主机、端口、用户名、密码）
- 确认数据库用户有足够的权限
- 检查防火墙设置

#### 2. AI API 调用失败

**错误信息**：`401 Unauthorized` 或 `Rate limit exceeded`

**解决方案**：
- 检查 DeepSeek API Key 是否正确
- 确认 API Key 有足够的配额
- 如果遇到限流，减小 `batchSize` 或增加请求间隔

#### 3. 保存文件失败

**错误信息**：`This operation expects the node's input data to contain a binary file`

**解决方案**：
- 确保 **发布准备** 节点正确输出了 `binary.raw_content`
- 检查输出目录是否存在（`./outputs/report/` 和 `./content-to-publish/`）
- 确认 n8n 有写入权限

#### 4. 关键词查询无结果

**可能原因**：
- 关键词拼写错误
- 数据库中确实没有该关键词的数据
- 时间范围设置过短

**解决方案**：
- 先执行 **抖音关键词列表** 节点，查看可用关键词
- 扩大时间范围（增加 `days` 值）
- 检查数据库中是否有数据

#### 5. AI 分类结果为空

**可能原因**：
- AI API 返回格式不正确
- 批量数据过大，超过 token 限制
- AI 响应解析失败

**解决方案**：
- 检查 **AI批量分类** 节点的输出，查看原始响应
- 减小 `batchSize`
- 检查 **解析批量分类结果** 节点的日志

### 调试技巧

#### 1. 查看节点输出

- 点击每个节点，查看 "OUTPUT" 面板
- 确认数据格式是否符合预期
- 检查数据量是否正确

#### 2. 使用测试模式
