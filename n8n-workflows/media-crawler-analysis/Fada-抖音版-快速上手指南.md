# Fada抖音工作流 - 快速上手指南

5 分钟快速上手 Fada抖音数据分析工作流。

## ⚡ 超快速开始（3步）

### 第1步：导入工作流

1. 打开 n8n
2. 点击 **Workflows** → **Import from File**
3. 选择 `workflow-templates/Fada-抖音版数据分析.json`

### 第2步：配置连接

#### 配置数据库（2个节点）

找到这两个节点，配置 MySQL 连接：
- **数据库查询**
- **抖音关键词列表**

**配置信息**：
- Host：你的数据库地址
- Database：`media_crawler`
- User：数据库用户名
- Password：数据库密码

#### 配置 AI API（2个节点）

找到这两个节点，配置 DeepSeek API：
- **AI批量分类**
- **AI生成内容**

**配置信息**：
- 选择 **HTTP Bearer Auth**
- Token：你的 DeepSeek API Key

### 第3步：设置参数并运行

1. 找到 **工作流参数** 节点
2. 修改 `keywords_raw` 字段，例如：`论文,AI,毕业论文`
3. 修改 `days` 字段，例如：`180`（最近 180 天）
4. 点击右上角 **Execute Workflow** 运行

## 📋 参数配置速查表

### 工作流参数节点

| 字段 | 类型 | 说明 | 示例值 |
|------|------|------|--------|
| `keywords_raw` | String | 关键词列表（逗号分隔） | `论文,AI,毕业论文` |
| `days` | Number | 查询最近 N 天 | `180` |
| `limit` | Number | 最多查询条数 | `1000` |
| `useSourceKeyword` | Boolean | 使用 source_keyword 字段 | `true` |

### 推荐配置组合

#### 配置1：快速测试（少量数据）
```json
{
  "keywords_raw": "论文",
  "days": 7,
  "limit": 20,
  "useSourceKeyword": true
}
```

#### 配置2：日常分析（中等数据量）
```json
{
  "keywords_raw": "论文,AI,毕业论文",
  "days": 30,
  "limit": 500,
  "useSourceKeyword": true
}
```

#### 配置3：深度分析（大量数据）
```json
{
  "keywords_raw": "论文,AI,毕业论文,本科论文,研究生",
  "days": 180,
  "limit": 1000,
  "useSourceKeyword": true
}
```

## 🎯 工作流执行流程

### 执行顺序

```
1. 手动触发
   ↓
2. 抖音关键词列表（可选，用于查看可用关键词）
   ↓
3. 工作流参数 → 解析关键词参数 → 数据查询-SQL生成
   ↓
4. 数据库查询（获取原始数据）
   ↓
5. 数据验证 → 过滤有效数据 → 数据清洗
   ↓
6. 准备批量分类 → AI批量分类 → 合并AI响应 → 解析批量分类结果
   ↓
7. 过滤低置信度 → 数据分组 → 计算Top10 → 统计分析
   ↓
8. 生成报表 → 保存报表（HTML）
   ↓
9. 生成内容生成上下文 → 格式化内容生成提示词 → AI生成内容
   ↓
10. 格式化内容 → 发布准备 → 保存内容（Markdown + JSON）
```

### 预期执行时间

| 数据量 | 预计时间 | 说明 |
|--------|----------|------|
| 20 条 | 1-2 分钟 | 快速测试 |
| 100 条 | 3-5 分钟 | 日常分析 |
| 500 条 | 10-15 分钟 | 深度分析 |
| 1000 条 | 20-30 分钟 | 完整分析 |

**注意**：执行时间主要取决于 AI API 的响应速度。

## 📂 输出文件位置

### HTML 报表

**路径**：`./outputs/report/report_[timestamp].html`

**内容**：
- 总体统计
- 分类统计
- Top10 热门内容

**打开方式**：用浏览器直接打开

### 生成的文章

**Markdown 文件**：`./content-to-publish/douyin_[timestamp].md`  
**元数据文件**：`./content-to-publish/douyin_[timestamp].json`

**内容**：
- 完整的文章内容（Markdown 格式）
- 标题、正文、标签
- 元数据（生成时间、字数、标签等）

## ⚠️ 常见问题快速解决

### 问题1：数据库连接失败

**快速检查**：
- [ ] 数据库服务是否运行？
- [ ] 连接信息是否正确？
- [ ] 数据库用户是否有权限？

### 问题2：AI API 调用失败

**快速检查**：
- [ ] API Key 是否正确？
- [ ] API Key 是否有配额？
- [ ] 网络连接是否正常？

### 问题3：没有查询到数据

**快速检查**：
- [ ] 关键词是否正确？
- [ ] 时间范围是否合适？
- [ ] 数据库中是否有数据？

**解决方法**：
1. 先执行 **抖音关键词列表** 节点，查看可用关键词
2. 扩大时间范围（增加 `days`）
3. 检查数据库中的数据

### 问题4：保存文件失败

**快速检查**：
- [ ] 输出目录是否存在？
- [ ] n8n 是否有写入权限？

**解决方法**：
1. 手动创建目录：`./outputs/report/` 和 `./content-to-publish/`
2. 检查目录权限

## 💡 使用技巧

### 技巧1：先查看可用关键词

在设置参数前，先单独执行 **抖音关键词列表** 节点，了解数据库中有哪些关键词可用。

### 技巧2：从小数据量开始

首次使用时，建议设置 `limit: 20`，快速测试整个流程是否正常。

### 技巧3：调整批量大小

如果遇到 AI API token 限制错误，在 **准备批量分类** 节点中减小 `batchSize`（例如：从 60 改为 30）。

### 技巧4：查看节点输出

每个节点执行后，点击节点查看 OUTPUT，确认数据格式和内容是否正确。
