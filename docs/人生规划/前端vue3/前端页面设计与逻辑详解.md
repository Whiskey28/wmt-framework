## 1. 页面设计思路

### 1.1 为什么这样布局？

**前端页面的设计原则：**

```
用户操作 → 触发事件 → 修改数据 → 视图自动更新
```

**对比后端思维：**

```java
// 后端：请求 → 处理 → 返回
@PostMapping("/save")
public Result save(@RequestBody UserDTO dto) {
    userService.save(dto);
    return Result.success();
}
```

```typescript
// 前端：用户点击 → 事件处理 → 调用API → 更新数据 → 视图刷新
const handleSave = async () => {
  await UserApi.save(formData)  // 调用API
  list.value = await UserApi.getList()  // 更新数据
  // 视图自动刷新（Vue的响应式系统）
}
```

### 1.2 页面结构设计

**列表页面的标准结构：**

```
┌─────────────────────────────────────┐
│  搜索区域（Search Area）            │
│  - 搜索条件输入框                   │
│  - 搜索/重置按钮                    │
│  - 操作按钮（新增、导入、导出等）   │
└─────────────────────────────────────┘
┌─────────────────────────────────────┐
│  数据展示区域（Table Area）          │
│  - 数据表格                          │
│  - 操作列（修改、删除按钮）          │
└─────────────────────────────────────┘
┌─────────────────────────────────────┐
│  分页区域（Pagination Area）         │
│  - 当前页/总页数                     │
│  - 每页条数选择                      │
└─────────────────────────────────────┘
┌─────────────────────────────────────┐
│  表单对话框（Dialog，默认隐藏）      │
│  - 表单字段                          │
│  - 提交/取消按钮                     │
└─────────────────────────────────────┘
```

**设计原因：**

1. **搜索区域放在顶部**：用户习惯先搜索，再查看结果
2. **表格在中间**：主要数据展示区域，占据最大空间
3. **分页在底部**：符合用户阅读习惯
4. **表单用对话框**：不占用页面空间，需要时才显示

## 2. 数据流详解

### 2.1 数据的生命周期

**完整的数据流：**

```
页面加载
  ↓
onMounted() 执行
  ↓
调用 getList() 方法
  ↓
设置 loading = true（显示加载动画）
  ↓
调用 API：UserApi.getUserPage(queryParams)
  ↓
等待后端返回数据
  ↓
设置 list.value = data.list（更新列表数据）
  ↓
设置 total.value = data.total（更新总条数）
  ↓
设置 loading = false（隐藏加载动画）
  ↓
Vue自动检测到 list 变化
  ↓
自动重新渲染表格（视图更新）
```

### 2.2 数据定义详解

#### 2.2.1 为什么用 `ref` 和 `reactive`？

```typescript
// ❌ 错误：普通变量不会触发视图更新
let list = []  // 修改后，视图不会更新

// ✅ 正确：ref 让数据变成响应式
const list = ref([])  // 修改后，视图自动更新
list.value = [1, 2, 3]  // 注意：需要用 .value 访问
```

**选择规则：**

- **基本类型**（string, number, boolean）→ 用 `ref`
- **对象类型**（Object, Array）→ 用 `reactive` 或 `ref`

```typescript
// 基本类型 → ref
const loading = ref(false)
const total = ref(0)

// 对象类型 → reactive（推荐，直接访问属性）
const queryParams = reactive({
  pageNo: 1,
  pageSize: 10,
  keyword: undefined
})
// 访问：queryParams.pageNo（不需要 .value）

// 对象类型 → ref（也可以，但需要 .value）
const queryParams = ref({
  pageNo: 1,
  pageSize: 10
})
// 访问：queryParams.value.pageNo（需要 .value）
```

#### 2.2.2 数据的作用域

```typescript
<script setup lang="ts">
// ========== 1. 列表相关数据 ==========
const list = ref([])           // 表格数据
const total = ref(0)           // 总条数
const loading = ref(false)     // 加载状态

// ========== 2. 查询相关数据 ==========
const queryParams = reactive({
  pageNo: 1,      // 当前页
  pageSize: 10,   // 每页条数
  keyword: undefined  // 搜索关键词
})

// ========== 3. 表单相关数据 ==========
const formRef = ref()          // 表单组件引用（用于调用子组件方法）
const dialogVisible = ref(false)  // 对话框显示状态（在子组件中）

// ========== 4. 其他数据 ==========
const checkedIds = ref([])     // 选中的行ID（批量操作）
</script>
```

**数据分类的目的：**

- **列表数据**：用于表格展示
- **查询数据**：用于API请求参数
- **表单数据**：用于表单输入和提交
- **状态数据**：用于控制UI显示（loading、dialogVisible等）

### 2.3 数据绑定详解

#### 2.3.1 单向绑定（`:prop`）

```vue
<el-table :data="list" />
```

**含义：**
- `:data` 是 `v-bind:data` 的简写
- 将 `list` 的值绑定到表格的 `data` 属性
- **单向**：数据 → 视图（数据变化，视图更新；视图变化，数据不变）

**数据流：**
```
list.value = [...]  （修改数据）
  ↓
Vue检测到变化
  ↓
自动更新 <el-table :data="list" />  （视图更新）
```

#### 2.3.2 双向绑定（`v-model`）

```vue
<el-input v-model="queryParams.keyword" />
```

**含义：**
- **双向**：数据 ↔ 视图
- 用户输入 → 自动更新 `queryParams.keyword`
- 代码修改 `queryParams.keyword` → 自动更新输入框

**数据流：**
```
用户输入 "张三"
  ↓
自动更新 queryParams.keyword = "张三"
  ↓
代码修改 queryParams.keyword = "李四"
  ↓
自动更新输入框显示 "李四"
```

#### 2.3.3 事件绑定（`@event`）

```vue
<el-button @click="handleQuery">搜索</el-button>
```

**含义：**
- `@click` 是 `v-on:click` 的简写
- 当用户点击按钮时，执行 `handleQuery` 方法

**数据流：**
```
用户点击按钮
  ↓
触发 click 事件
  ↓
执行 handleQuery() 方法
  ↓
方法内部修改数据或调用API
  ↓
数据变化 → 视图更新
```

## 3. 事件逻辑详解

### 3.1 事件触发的完整流程

**以"搜索"功能为例：**

```vue
<template>
  <!-- 1. 用户输入搜索关键词 -->
  <el-input
    v-model="queryParams.keyword"
    @keyup.enter="handleQuery"  <!-- 2. 回车键触发搜索 -->
  />
  
  <!-- 3. 用户点击搜索按钮 -->
  <el-button @click="handleQuery">搜索</el-button>
</template>

<script setup lang="ts">
// 4. 定义搜索方法
const handleQuery = () => {
  // 5. 重置到第一页
  queryParams.pageNo = 1
  
  // 6. 调用获取列表方法
  getList()
}

// 7. 获取列表方法
const getList = async () => {
  // 8. 显示加载动画
  loading.value = true
  
  try {
    // 9. 调用API（携带查询参数）
    const data = await UserApi.getUserPage(queryParams)
    
    // 10. 更新列表数据
    list.value = data.list
    
    // 11. 更新总条数
    total.value = data.total
  } finally {
    // 12. 隐藏加载动画
    loading.value = false
  }
}
</script>
```

**完整流程图：**

```
用户操作
  ↓
触发事件（@click / @keyup.enter）
  ↓
执行事件处理方法（handleQuery）
  ↓
修改数据（queryParams.pageNo = 1）
  ↓
调用API方法（getList）
  ↓
显示加载状态（loading = true）
  ↓
发送HTTP请求（UserApi.getUserPage）
  ↓
等待后端响应
  ↓
接收数据（data.list, data.total）
  ↓
更新数据（list.value = data.list）
  ↓
隐藏加载状态（loading = false）
  ↓
Vue检测到数据变化
  ↓
自动重新渲染视图
  ↓
用户看到更新后的表格
```

### 3.2 常见事件类型

#### 3.2.1 点击事件（`@click`）

```vue
<!-- 搜索按钮 -->
<el-button @click="handleQuery">搜索</el-button>

<!-- 新增按钮 -->
<el-button @click="openForm('create')">新增</el-button>

<!-- 删除按钮 -->
<el-button @click="handleDelete(row.id)">删除</el-button>
```

**事件处理函数：**

```typescript
// 无参数
const handleQuery = () => {
  queryParams.pageNo = 1
  getList()
}

// 有参数（字符串）
const openForm = (type: string) => {
  formRef.value?.open(type)
}

// 有参数（数字）
const handleDelete = (id: number) => {
  // 处理删除逻辑
}
```

#### 3.2.2 键盘事件（`@keyup.enter`）

```vue
<el-input
  v-model="queryParams.keyword"
  @keyup.enter="handleQuery"  <!-- 回车键触发搜索 -->
/>
```

**为什么用 `@keyup.enter`？**
- 提升用户体验：输入完成后按回车即可搜索，无需点击按钮

#### 3.2.3 选择变化事件（`@selection-change`）

```vue
<el-table
  :data="list"
  @selection-change="handleRowCheckboxChange"  <!-- 多选变化时触发 -->
>
  <el-table-column type="selection" />
</el-table>
```

**事件处理：**

```typescript
const checkedIds = ref<number[]>([])

// 当用户勾选/取消勾选行时，自动触发
const handleRowCheckboxChange = (rows: UserVO[]) => {
  // rows: 当前选中的所有行数据
  checkedIds.value = rows.map(row => row.id)  // 提取所有ID
}
```

**数据流：**
```
用户勾选表格行
  ↓
触发 @selection-change 事件
  ↓
执行 handleRowCheckboxChange(rows)
  ↓
更新 checkedIds.value = [1, 2, 3]
  ↓
批量删除按钮自动启用/禁用（:disabled="checkedIds.length === 0"）
```

#### 3.2.4 分页变化事件（`@pagination`）

```vue
<Pagination
  :total="total"
  v-model:page="queryParams.pageNo"
  v-model:limit="queryParams.pageSize"
  @pagination="getList"  <!-- 分页变化时触发 -->
/>
```

**工作原理：**

```
用户点击分页（第2页）
  ↓
自动更新 queryParams.pageNo = 2（v-model:page 双向绑定）
  ↓
触发 @pagination 事件
  ↓
执行 getList() 方法
  ↓
使用新的 pageNo 调用API
  ↓
获取第2页数据
  ↓
更新表格
```

### 3.3 异步事件处理

#### 3.3.1 为什么用 `async/await`？

```typescript
// ❌ 错误：不用 async/await，无法等待API返回
const handleDelete = (id: number) => {
  UserApi.deleteUser(id)  // 不等待，立即执行下一行
  message.success('删除成功')  // 可能API还没完成
  getList()  // 可能删除还没完成就刷新列表
}

// ✅ 正确：用 async/await，等待API完成
const handleDelete = async (id: number) => {
  await UserApi.deleteUser(id)  // 等待删除完成
  message.success('删除成功')  // 删除成功后才提示
  await getList()  // 删除成功后才刷新列表
}
```

#### 3.3.2 错误处理

```typescript
const handleDelete = async (id: number) => {
  try {
    // 1. 确认对话框（用户可能取消）
    await message.delConfirm()
    
    // 2. 调用删除API
    await UserApi.deleteUser(id)
    
    // 3. 显示成功提示
    message.success('删除成功')
    
    // 4. 刷新列表
    await getList()
  } catch {
    // 5. 用户取消或API失败，不执行任何操作
    // catch 块可以为空，表示静默处理
  }
}
```

**错误处理场景：**

- **用户取消确认对话框** → 进入 catch，不执行删除
- **API调用失败** → 进入 catch，不显示成功提示
- **网络错误** → 进入 catch，不刷新列表

## 4. 组件通信详解

### 4.1 父组件 → 子组件（Props）

**在列表页面（父组件）：**

```vue
<template>
  <!-- 使用子组件 -->
  <UserForm ref="formRef" @success="getList" />
</template>

<script setup lang="ts">
const formRef = ref()  // 获取子组件引用

// 调用子组件方法
const openForm = (type: string, id?: number) => {
  formRef.value.open(type, id)  // 调用子组件的 open 方法
}
</script>
```

**在表单组件（子组件）：**

```vue
<script setup lang="ts">
// 子组件不需要接收 props（这个例子中）
// 但需要暴露方法给父组件

// 定义打开表单的方法
const open = async (type: string, id?: number) => {
  dialogVisible.value = true  // 显示对话框
  formType.value = type       // 设置表单类型
  // ... 其他逻辑
}

// 暴露方法给父组件
defineExpose({ open })
</script>
```

**通信流程：**

```
父组件（列表页面）
  ↓
用户点击"新增"按钮
  ↓
执行 openForm('create')
  ↓
调用 formRef.value.open('create')
  ↓
子组件（表单组件）的 open 方法执行
  ↓
显示对话框（dialogVisible = true）
  ↓
用户填写表单并提交
  ↓
子组件发送 success 事件
  ↓
父组件监听到 @success 事件
  ↓
执行 getList() 刷新列表
```

### 4.2 子组件 → 父组件（Emits）

**在表单组件（子组件）：**

```vue
<script setup lang="ts">
// 1. 定义要发送的事件
const emit = defineEmits<{
  success: []  // 成功事件，无参数
}>()

// 2. 提交表单成功后，发送事件
const submitForm = async () => {
  // ... 提交逻辑
  await UserApi.createUser(formData)
  message.success('创建成功')
  
  // 3. 发送 success 事件给父组件
  emit('success')
}
</script>
```

**在列表页面（父组件）：**

```vue
<template>
  <!-- 监听子组件的 success 事件 -->
  <UserForm ref="formRef" @success="getList" />
</template>

<script setup lang="ts">
// 当子组件发送 success 事件时，自动执行 getList()
const getList = async () => {
  // 刷新列表
}
</script>
```

**通信流程：**

```
子组件（表单组件）
  ↓
用户点击"确定"按钮
  ↓
执行 submitForm()
  ↓
调用API创建用户
  ↓
创建成功
  ↓
执行 emit('success')
  ↓
父组件（列表页面）监听到 @success
  ↓
自动执行 getList()
  ↓
刷新列表数据
```

### 4.3 组件引用（Ref）

**为什么需要 `ref`？**

```vue
<!-- 父组件 -->
<template>
  <!-- ref="formRef" 获取子组件实例 -->
  <UserForm ref="formRef" />
</template>

<script setup lang="ts">
const formRef = ref()  // 存储子组件引用

// 通过 ref 调用子组件方法
const openForm = () => {
  formRef.value.open('create')  // 调用子组件的 open 方法
}
</script>
```

**对比Java：**

```java
// Java中直接调用方法
UserForm form = new UserForm();
form.open("create");
```

```typescript
// Vue中需要通过 ref 获取组件实例
const formRef = ref()  // 类似 Java 的引用
formRef.value.open('create')  // 通过引用调用方法
```

## 5. 完整案例：客户管理功能

### 5.1 列表页面完整解析

```vue
<template>
  <!-- ========== 第一部分：搜索区域 ========== -->
  <ContentWrap>
    <el-form :model="queryParams" :inline="true" ref="queryFormRef">
      <!-- 
        设计思路：
        1. :model="queryParams" - 绑定查询参数对象
        2. :inline="true" - 表单项横向排列
        3. ref="queryFormRef" - 获取表单引用，用于重置
      -->
      
      <!-- 客户名称搜索 -->
      <el-form-item label="客户名称" prop="name">
        <!-- 
          设计思路：
          1. v-model="queryParams.name" - 双向绑定，用户输入自动更新 queryParams.name
          2. @keyup.enter="handleQuery" - 回车键触发搜索，提升用户体验
          3. clearable - 显示清除按钮
        -->
        <el-input
          v-model="queryParams.name"
          placeholder="请输入客户名称"
          @keyup.enter="handleQuery"
          clearable
        />
      </el-form-item>

      <!-- 手机号码搜索 -->
      <el-form-item label="手机号码" prop="mobile">
        <el-input
          v-model="queryParams.mobile"
          placeholder="请输入手机号码"
          @keyup.enter="handleQuery"
          clearable
        />
      </el-form-item>

      <!-- 操作按钮 -->
      <el-form-item>
        <!-- 
          设计思路：
          1. @click="handleQuery" - 点击搜索按钮，执行搜索
          2. @click="resetQuery" - 点击重置按钮，清空搜索条件
          3. @click="openForm('create')" - 点击新增按钮，打开表单对话框
        -->
        <el-button @click="handleQuery">搜索</el-button>
        <el-button @click="resetQuery">重置</el-button>
        <el-button type="primary" @click="openForm('create')">新增</el-button>
      </el-form-item>
    </el-form>
  </ContentWrap>

  <!-- ========== 第二部分：数据表格 ========== -->
  <ContentWrap>
    <!-- 
      设计思路：
      1. v-loading="loading" - 数据加载时显示加载动画
      2. :data="list" - 绑定列表数据，表格自动渲染
      3. @selection-change="handleRowCheckboxChange" - 多选变化时触发
    -->
    <el-table v-loading="loading" :data="list" @selection-change="handleRowCheckboxChange">
      <!-- 多选列 -->
      <el-table-column type="selection" width="55" />

      <!-- 数据列 -->
      <el-table-column label="客户编号" prop="id" />
      <el-table-column label="客户名称" prop="name" />
      <el-table-column label="手机号码" prop="mobile" />

      <!-- 操作列 -->
      <el-table-column label="操作" width="160">
        <template #default="scope">
          <!-- 
            设计思路：
            1. scope.row - 当前行的数据对象
            2. scope.row.id - 当前行的ID
            3. @click="openForm('update', scope.row.id)" - 点击修改，打开表单并传入ID
            4. @click="handleDelete(scope.row.id)" - 点击删除，传入ID
          -->
          <el-button @click="openForm('update', scope.row.id)">修改</el-button>
          <el-button type="danger" @click="handleDelete(scope.row.id)">删除</el-button>
        </template>
      </el-table-column>
    </el-table>

    <!-- ========== 第三部分：分页 ========== -->
    <!-- 
      设计思路：
      1. :total="total" - 总条数，用于计算总页数
      2. v-model:page="queryParams.pageNo" - 双向绑定当前页，用户切换页码时自动更新
      3. v-model:limit="queryParams.pageSize" - 双向绑定每页条数
      4. @pagination="getList" - 分页变化时，重新加载数据
    -->
    <Pagination
      :total="total"
      v-model:page="queryParams.pageNo"
      v-model:limit="queryParams.pageSize"
      @pagination="getList"
    />
  </ContentWrap>

  <!-- ========== 第四部分：表单对话框（默认隐藏） ========== -->
  <!-- 
    设计思路：
    1. ref="formRef" - 获取表单组件引用，用于调用子组件方法
    2. @success="getList" - 监听子组件的 success 事件，成功后刷新列表
  -->
  <CustomerForm ref="formRef" @success="getList" />
</template>

<script setup lang="ts">
import * as CustomerApi from '@/api/crm/customer'
import CustomerForm from './CustomerForm.vue'
import { message } from '@/utils/message'

// ========== 数据定义 ==========

// 1. 列表数据
const list = ref([])           // 表格数据
const total = ref(0)           // 总条数
const loading = ref(false)     // 加载状态（控制加载动画）

// 2. 查询参数
const queryParams = reactive({
  pageNo: 1,        // 当前页

  mobile: undefined // 手机号码（搜索条件）

/**
 * 获取列表数据
 * 
 * 设计思路：
 * 1. 设置 loading = true，显示加载动画
 * 2. 调用API，传入查询参数
 * 3. 接收返回数据，更新 list 和 total
 * 4. 设置 loading = false，隐藏加载动画
 * 5. Vue自动检测到 list 变化，重新渲染表格

const getList = async () => {
  loading.value = true  // 显示加载动画
  try {
    // 调用API，传入查询参数
    const data = await CustomerApi.getCustomerPage(queryParams)
    
    // 更新列表数据
    list.value = data.list      // 表格数据
    total.value = data.total    // 总条数
    
    // Vue自动检测到 list.value 变化，重新渲染表格
  } finally {
    loading.value = false  // 隐藏加载动画
  }
}

/**

const handleQuery = () => {

/**

 * 2. 调用 handleQuery() 重新加载数据

const resetQuery = () => {

  handleQuery()                        // 重新加载数据

/**

const openForm = (type: 'create' | 'update', id?: number) => {
  formRef.value?.open(type, id)  // 调用子组件的 open 方法

/**

 * 4. 刷新列表数据
 * 5. 如果用户取消或API失败，catch 块处理（静默失败）
 */
const handleDelete = async (id: number) => {
  try {
    // 1. 确认对话框
    await message.delConfirm()
    
    // 2. 调用删除API
    await CustomerApi.deleteCustomer(id)
    
    // 3. 显示成功提示
    message.success('删除成功')
    
    // 4. 刷新列表
    await getList()
  } catch {
    // 5. 用户取消或API失败，不执行任何操作
  }

/**

const handleRowCheckboxChange = (rows: CustomerApi.CustomerVO[]) => {
```

### 5.2 表单组件完整解析

```vue
<template>
  <!-- ========== 对话框组件 ========== -->
  <!-- 
    设计思路：
    1. v-model="dialogVisible" - 双向绑定，控制对话框显示/隐藏
       - dialogVisible = true → 显示对话框
       - dialogVisible = false → 隐藏对话框
    2. :title="dialogTitle" - 动态标题（新增/修改）
  -->
  <Dialog v-model="dialogVisible" :title="dialogTitle">
    
    <!-- ========== 表单 ========== -->
    <!-- 
      设计思路：
      1. ref="formRef" - 获取表单引用，用于表单验证和重置
      2. :model="formData" - 绑定表单数据对象
      3. :rules="formRules" - 绑定验证规则
      4. v-loading="formLoading" - 提交时显示加载动画
    -->
    <el-form
      ref="formRef"
      v-loading="formLoading"
      :model="formData"
      :rules="formRules"
      label-width="100px"
    >
      <!-- 客户名称 -->
      <el-form-item label="客户名称" prop="name">
        <!-- 
          设计思路：
          1. v-model="formData.name" - 双向绑定，用户输入自动更新 formData.name
          2. prop="name" - 对应验证规则中的 name 字段
        -->
        <el-input v-model="formData.name" placeholder="请输入客户名称" />
      </el-form-item>

      <!-- 手机号码 -->
      <el-form-item label="手机号码" prop="mobile">
        <el-input v-model="formData.mobile" placeholder="请输入手机号码" />
      </el-form-item>

      <!-- 邮箱 -->
      <el-form-item label="邮箱" prop="email">
        <el-input v-model="formData.email" placeholder="请输入邮箱" />
      </el-form-item>
    </el-form>

    <!-- ========== 对话框底部按钮 ========== -->
    <template #footer>
      <!-- 
        设计思路：
        1. :disabled="formLoading" - 提交时禁用按钮，防止重复提交
        2. @click="submitForm" - 点击确定，提交表单
        3. @click="dialogVisible = false" - 点击取消，关闭对话框
      -->
      <el-button :disabled="formLoading" type="primary" @click="submitForm">
        确定
      </el-button>
      <el-button @click="dialogVisible = false">取消</el-button>
    </template>
  </Dialog>
</template>

<script setup lang="ts">
import * as CustomerApi from '@/api/crm/customer'
import { message } from '@/utils/message'

// ========== 数据定义 ==========

// 1. 对话框状态
const dialogVisible = ref(false)   // 对话框显示/隐藏
const formLoading = ref(false)      // 表单提交加载状态
const formType = ref<'create' | 'update'>('create')  // 表单类型

// 2. 表单数据
const formData = reactive({
  id: undefined,    // ID（新增时undefined，修改时有值）
  name: '',         // 客户名称
  mobile: '',       // 手机号码
  email: ''         // 邮箱
})

// 3. 表单验证规则
const formRules = {
  name: [
    { required: true, message: '请输入客户名称', trigger: 'blur' }
  ],
  mobile: [
    { required: true, message: '请输入手机号码', trigger: 'blur' },
    { pattern: /^1[3-9]\d{9}$/, message: '手机号码格式不正确', trigger: 'blur' }
  ],
  email: [
    { type: 'email', message: '邮箱格式不正确', trigger: 'blur' }
  ]
}

// 4. 表单引用
const formRef = ref()  // 表单引用（用于验证和重置）

// 5. 计算属性：对话框标题
const dialogTitle = computed(() => {
  return formType.value === 'create' ? '新增客户' : '修改客户'
})

// ========== 方法定义 ==========

/**
 * 打开表单对话框
 * 
 * 设计思路：
 * 1. 设置表单类型（create/update）
 * 2. 显示对话框
 * 3. 如果是修改模式，加载数据
 * 4. 如果是新增模式，重置表单
 * 
 * 调用方式：
 * - 父组件：formRef.value.open('create')
 * - 父组件：formRef.value.open('update', 123)
 */
const open = async (type: 'create' | 'update', id?: number) => {
  formType.value = type              // 设置表单类型
  dialogVisible.value = true         // 显示对话框
  
  if (type === 'update' && id) {
    // 修改模式：加载数据
    await loadData(id)
  } else {
    // 新增模式：重置表单
    resetForm()
  }
}

/**
 * 加载数据（修改模式）
 * 
 * 设计思路：
 * 1. 显示加载动画
 * 2. 调用API获取详情数据
 * 3. 将数据填充到表单
 * 4. 隐藏加载动画
 */
const loadData = async (id: number) => {
  formLoading.value = true  // 显示加载动画
  try {
    // 调用API获取详情
    const data = await CustomerApi.getCustomer(id)
    
    // 将数据填充到表单（Object.assign 合并对象）
    Object.assign(formData, data)
  } finally {
    formLoading.value = false  // 隐藏加载动画
  }
}

/**
 * 提交表单
 * 
 * 设计思路：
 * 1. 表单验证（如果验证失败，不继续执行）
 * 2. 显示加载状态
 * 3. 根据表单类型，调用不同的API
 * 4. 提交成功后，关闭对话框
 * 5. 发送 success 事件给父组件（触发列表刷新）
 * 6. 隐藏加载状态
 */
const submitForm = async () => {
  // 1. 表单验证
  if (!formRef.value) return
  const valid = await formRef.value.validate()
  if (!valid) return  // 验证失败，不继续执行

  // 2. 显示加载状态
  formLoading.value = true
  
  try {
    // 3. 根据表单类型，调用不同的API
    if (formType.value === 'create') {
      // 新增
      await CustomerApi.createCustomer(formData)
      message.success('创建成功')
    } else {
      // 修改
      await CustomerApi.updateCustomer(formData)
      message.success('修改成功')
    }
    
    // 4. 关闭对话框
    dialogVisible.value = false
    
    // 5. 发送 success 事件给父组件
    emit('success')
  } finally {
    // 6. 隐藏加载状态
    formLoading.value = false
  }
}

/**
 * 重置表单
 * 
 * 设计思路：
 * 1. 重置表单数据为初始值
 * 2. 清除表单验证状态
 */
const resetForm = () => {
  Object.assign(formData, {
    id: undefined,
    name: '',
    mobile: '',
    email: ''
  })
  formRef.value?.resetFields()  // 清除验证状态
}

// ========== 组件通信 ==========

/**
 * 定义要发送的事件
 * 
 * 设计思路：
 * 1. success 事件：表单提交成功后发送
 * 2. 父组件通过 @success="getList" 监听
 * 3. 当子组件 emit('success') 时，父组件自动执行 getList()
 */
const emit = defineEmits<{
  success: []  // 成功事件，无参数
}>()

/**
 * 暴露方法给父组件
 * 
 * 设计思路：
 * 1. defineExpose 用于暴露方法给父组件
 * 2. 父组件通过 ref 获取子组件实例后，可以调用 open 方法
 * 3. 类似 Java 的 public 方法
 */
defineExpose({ open })
</script>
```

## 🎯 核心要点总结

### 1. 数据驱动视图

**核心思想：**
- 定义数据 → 绑定数据 → 修改数据 → 视图自动更新

**实现方式：**
- 用 `ref` 或 `reactive` 定义响应式数据
- 用 `v-model` 或 `:prop` 绑定数据
- 修改数据后，Vue自动更新视图

### 2. 事件驱动逻辑

**核心思想：**
- 用户操作 → 触发事件 → 执行方法 → 修改数据 → 视图更新

**实现方式：**
- 用 `@click`、`@keyup` 等绑定事件
- 定义事件处理方法
- 在方法中修改数据或调用API

### 3. 组件通信

**核心思想：**
- 父组件通过 `ref` 调用子组件方法
- 子组件通过 `emit` 发送事件给父组件

**实现方式：**
- 父→子：`formRef.value.open()`
- 子→父：`emit('success')` + `@success="getList"`

### 4. 异步处理

**核心思想：**
- 用 `async/await` 等待API完成
- 用 `try/catch` 处理错误

**实现方式：**
```typescript
const handleDelete = async (id: number) => {
  try {
    await message.delConfirm()
    await CustomerApi.deleteCustomer(id)
    message.success('删除成功')
    await getList()
  } catch {
    // 错误处理
  }
}
```

---

**记住：前端开发 = 数据驱动视图 + 事件驱动逻辑**

**你只需要：**
1. **定义数据**（ref/reactive）
2. **绑定数据**（v-model/:prop）
3. **绑定事件**（@click/@keyup）
4. **处理事件**（修改数据/调用API）
5. **视图自动更新**（Vue的响应式系统）
