## 🚀 快速生成流程

### 第一步：填写需求清单

根据 `前端功能开发需求清单.md` 中的模板，填写你的需求信息。

### 第二步：提供需求信息

你可以用以下任意方式提供需求：

1. **直接描述**（我会帮你整理成清单）
   ```
   我需要一个商品管理功能：
   - 商品列表：显示商品名称、价格、库存、状态
   - 可以搜索商品名称和分类
   - 可以新增、编辑、删除商品
   - 商品表单：商品名称（必填）、价格（必填，数字）、分类（下拉选择）、库存（必填，数字）
   ```

2. **按照清单格式提供**（更高效）
   ```
   功能名称：商品管理
   
   表单字段：
   1. 商品名称 - 文本输入 - 必填 - 长度2-50
   2. 价格 - 数字输入 - 必填 - 大于0
   3. 分类 - 下拉选择 - 必填 - API: /api/category/list
   ...
   ```

3. **参考现有功能**（最快）
   ```
   参考用户管理功能，创建一个商品管理功能
   字段：商品名称、价格、库存、分类、状态
   ```

### 第三步：我生成代码

我会根据你的需求生成：

1. ✅ **API文件** - `src/api/xxx/index.ts`
2. ✅ **类型定义** - `src/api/xxx/types.ts`
3. ✅ **列表页面** - `src/views/xxx/index.vue`
4. ✅ **表单页面** - `src/views/xxx/xxxForm.vue`
5. ✅ **路由配置**（如果需要）

### 第四步：直接使用

生成的代码可以直接使用，只需要：
- 确认API路径是否正确
- 确认字段名称是否匹配后端
- 测试功能是否正常

## 🎯 关键要点

### 前端能做到什么？

1. **完整的CRUD功能**
   - ✅ 列表展示（搜索、分页、排序）
   - ✅ 新增数据（表单验证、提交）
   - ✅ 修改数据（数据回显、更新）
   - ✅ 删除数据（单个、批量）

2. **丰富的交互体验**
   - ✅ 实时搜索（防抖）
   - ✅ 加载状态提示
   - ✅ 操作确认对话框
   - ✅ 成功/失败提示

3. **数据验证**
   - ✅ 前端验证（格式、长度、必填）
   - ✅ 后端验证错误展示

4. **权限控制**
   - ✅ 按钮级权限
   - ✅ 页面级权限

### 前端不能做什么？

1. **数据安全**
   - ❌ 不能完全依赖前端验证（后端必须验证）
   - ❌ 不能在前端存储敏感信息

2. **业务逻辑**
   - ❌ 复杂业务逻辑应在后端处理
   - ❌ 前端主要负责展示和交互

3. **数据持久化**
   - ❌ 数据必须通过API保存到后端
