"我的代码报错：[错误信息]，帮我分析并解决"
"帮我优化这段代码：[代码]"
```

### 业务分析
```

"帮我设计一个XX功能的用户调研问卷"

## 📈 关键指标跟踪

### 技术指标
- **开发效率**：功能完成数/周
- **代码质量**：Bug数量/周
- **系统性能**：响应时间、并发数

### 业务指标
- **用户增长**：新增用户数/周
- **订单转化**：订单数/访问数
- **收入增长**：月收入、增长率
- **客户满意度**：满意度评分、复购率

### 管理指标
- **项目进度**：计划完成度
- **按时交付率**：按时交付项目数/总项目数
- **团队效率**：任务完成数/周

---

**使用说明**：
1. 每周更新执行清单，标记完成状态
2. 每月进行复盘，总结经验和教训
3. 每季度检查目标完成情况，调整计划
4. 持续跟踪关键指标，数据驱动决策
