# 每周计划模板与复盘机制

> 基于月度目标的周度执行计划与复盘体系

---

## 📅 周计划制定流程

### 第一步：回顾月度目标（周日晚上）
- 查看本月总体目标
- 评估上周完成情况
- 确定本周重点任务

### 第二步：制定周计划（周日晚上）
- 将月度目标分解为周任务
- 分配每日学习时间
- 设定可衡量的周目标

### 第三步：每日执行（周一到周日）
- 按照每日计划执行
- 记录完成情况
- 及时调整偏差

### 第四步：周末复盘（周日晚上）
- 总结本周成果
- 分析未完成任务原因
- 调整下周计划

## 🔄 复盘机制说明

### 复盘频率
- **每日复盘**：晚上22:00-22:30（30分钟）
- **周末复盘**：周日晚上22:30-23:00（30分钟）
- **月度复盘**：每月最后一天（1-2小时）

### 复盘原则
1. **客观真实**：如实记录完成情况，不自我欺骗
2. **深度分析**：不仅要记录做了什么，还要分析为什么
3. **持续改进**：根据复盘结果调整计划和方法
4. **保持记录**：所有复盘内容都要记录下来，便于回顾

### 复盘工具
- **笔记软件**：Notion、Obsidian、或Markdown文件
- **时间追踪**：Toggl、RescueTime等
- **任务管理**：Todoist、Trello等
