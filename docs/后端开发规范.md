## 一、代码规范

### 1.1 包结构规范

#### 标准包结构

```
com.ahzx.tdcp.module.{模块名}
├── controller/              # 控制器层
│   ├── admin/              # 管理后台接口
│   │   └── {功能}/
│   │       ├── XxxController.java
│   │       └── vo/         # 视图对象
│   │           ├── XxxPageReqVO.java    # 分页请求VO
│   │           ├── XxxSaveReqVO.java    # 创建/更新请求VO
│   │           └── XxxRespVO.java       # 响应VO
│   └── app/                # 移动端接口
├── service/                # 服务层
│   ├── XxxService.java     # 服务接口
│   └── impl/
│       └── XxxServiceImpl.java  # 服务实现
├── dal/                    # 数据访问层
│   ├── dataobject/         # 数据对象（DO）
│   │   └── {功能}/
│   │       └── XxxDO.java
│   └── mysql/              # Mapper接口
│       └── {功能}/
│           └── XxxMapper.java
├── enums/                  # 枚举类
│   └── ErrorCodeConstants.java
├── framework/              # 框架配置
│   └── web/
│       └── config/
└── vo/                     # 通用视图对象（可选）
```

#### 包命名规则

- **模块名**：小写字母，如 `customer`、`system`、`product`
- **功能名**：小写字母，如 `quota`、`order`、`user`
- **包名**：全小写，多个单词用点分隔

### 1.2 命名规范

#### 类命名规范

| 类型 | 命名规则 | 示例 |
|------|---------|------|
| Controller | `XxxController` | `CustomerQuotaController` |
| Service接口 | `XxxService` | `CustomerQuotaService` |
| Service实现 | `XxxServiceImpl` | `CustomerQuotaServiceImpl` |
| Mapper接口 | `XxxMapper` | `CustomerQuotaMapper` |
| DO（数据对象） | `XxxDO` | `CustomerQuotaDO` |
| 响应VO | `XxxRespVO` | `CustomerQuotaRespVO` |
| 分页请求VO | `XxxPageReqVO` | `CustomerQuotaPageReqVO` |
| 保存请求VO | `XxxSaveReqVO` | `CustomerQuotaSaveReqVO` |
| 枚举类 | `XxxEnum` | `OrderStatusEnum` |
| 错误码常量 | `ErrorCodeConstants` | `ErrorCodeConstants` |
| 配置类 | `XxxConfiguration` | `CustomerWebConfiguration` |

#### 方法命名规范

**Controller层方法命名：**

| 操作 | 方法名 | HTTP方法 | 示例 |
|------|--------|---------|------|
| 创建 | `createXxx` | POST | `createCustomerQuota` |
| 更新 | `updateXxx` | PUT | `updateCustomerQuota` |
| 删除 | `deleteXxx` | DELETE | `deleteCustomerQuota` |
| 单个查询 | `getXxx` | GET | `getCustomerQuota` |
| 分页查询 | `getXxxPage` | GET | `getCustomerQuotaPage` |
| 列表查询 | `listXxx` | GET | `listCustomerQuota` |

**Service层方法命名：**

- 与Controller层保持一致
- 返回类型：创建返回`Long`（ID），更新/删除返回`void`或`boolean`，查询返回对象或`PageResult`

#### 变量命名规范

- **驼峰命名**：`customerName`、`createTime`
- **布尔类型**：`isDeleted`、`hasPermission`
- **集合类型**：`customerList`、`orderMap`
- **常量**：全大写+下划线，`MAX_RETRY_COUNT`

### 1.3 注解使用规范

#### Controller层注解

```java
@Tag(name = "管理后台 - 客户额度管理")  // Swagger分组
@RestController
@RequestMapping("/customer/quota")
@Validated  // 类级别启用校验
public class CustomerQuotaController {
    
    @Resource
    private CustomerQuotaService customerQuotaService;
    
    @PostMapping("/create")
    @Operation(summary = "创建客户额度")  // Swagger方法描述
    @Parameter(name = "id", description = "编号", required = true)  // Swagger参数描述
    public CommonResult<Long> createCustomerQuota(
            @Valid @RequestBody CustomerQuotaSaveReqVO createReqVO) {
        // ...
    }
}
```

**注解说明：**

- `@RestController`：标识REST控制器
- `@RequestMapping`：定义基础路径
- `@Tag`：Swagger分组标签
- `@Operation`：Swagger方法描述
- `@Parameter`：Swagger参数描述（用于`@RequestParam`）
- `@Validated`：类级别启用校验
- `@Valid`：方法参数校验
- `@Resource`：依赖注入（推荐使用JSR-250标准）

#### Service层注解

```java
@Service
@Validated  // 启用方法参数校验
public class CustomerQuotaServiceImpl implements CustomerQuotaService {
    
    @Resource
    private CustomerQuotaMapper customerQuotaMapper;
    
    @Override
    public Long createCustomerQuota(@Valid CustomerQuotaSaveReqVO createReqVO) {
        // ...
    }
}
```

**注解说明：**

- `@Service`：标识服务类
- `@Validated`：启用方法参数校验
- `@Valid`：方法参数校验（配合`@Validated`使用）

#### Mapper层注解

```java
@Mapper
public interface CustomerQuotaMapper extends BaseMapperX<CustomerQuotaDO> {
    // ...
}
```

**注解说明：**

- `@Mapper`：标识Mapper接口

#### DO层注解

```java
@TableName("customer_quota")
@Data
@EqualsAndHashCode(callSuper = true)
@ToString(callSuper = true)
@Builder
@NoArgsConstructor
@AllArgsConstructor
```

**注解说明：**

- `@TableName`：指定表名
- `@TableId`：主键标识
- `@TableField`：字段映射（字段名与属性名不一致时使用）
- `@Data`：Lombok生成getter/setter
- `@Builder`：Lombok生成建造者模式
- `@NoArgsConstructor`：无参构造
- `@AllArgsConstructor`：全参构造
- `@EqualsAndHashCode(callSuper = true)`：包含父类字段
- `@ToString(callSuper = true)`：包含父类字段

**注解说明：**

- `@Schema`：Swagger字段描述

- `@JsonDeserialize`：JSON反序列化

### 1.4 返回值规范

#### 统一返回类型

**所有Controller方法必须返回`CommonResult<T>`：**

```java
// ✅ 正确示例
@GetMapping("/get")
public CommonResult<CustomerQuotaRespVO> getCustomerQuota(@NotNull @RequestParam("id") Long id) {
    CustomerQuotaRespVO quota = customerQuotaService.getCustomerQuota(id);
    return CommonResult.success(quota);
    // 或使用静态导入：return success(quota);
}

// ❌ 错误示例
@GetMapping("/get")
public CustomerQuotaRespVO getCustomerQuota(@NotNull @RequestParam("id") Long id) {
    return customerQuotaService.getCustomerQuota(id);
}
```

#### 成功返回

```java
// 方式1：使用完整类名
return CommonResult.success(data);

// 方式2：使用静态导入（推荐）
import static com.wmt.framework.common.pojo.CommonResult.success;
return success(data);

// 方式3：无数据返回
return success(true);
return success(null);
```

#### 失败返回

**失败通过异常机制处理，由全局异常处理器转换为`CommonResult`：**

```java
// Service层抛出异常
if (quota == null) {
    throw exception(ErrorCodeConstants.CUSTOMER_QUOTA_NOT_EXISTS);
}

// Controller层不需要捕获，全局异常处理器会自动处理
```

#### 分页返回

```java
@GetMapping("/page")
public CommonResult<PageResult<CustomerQuotaRespVO>> getCustomerQuotaPage(
        @Valid CustomerQuotaPageReqVO pageReqVO) {
    PageResult<CustomerQuotaRespVO> pageResult = customerQuotaService.getCustomerQuotaPage(pageReqVO);
    return success(pageResult);
}
```

### 1.5 分页规范

#### 分页请求参数

**统一使用`PageParam`或`SortablePageParam`：**

```java
// 基础分页（不支持排序）
public class XxxPageReqVO extends PageParam {
    private String name;
    // ...
}

// 支持排序的分页（推荐）
public class CustomerQuotaPageReqVO extends SortablePageParam {
    @Schema(description = "申请企业名", example = "测试企业")
    private String entName;
    
    @Schema(description = "统一社会信用代码", example = "91110000MA00123456")
    private String creditCode;
    
    // 排序字段通过父类的sortingFields属性传递
}
```

**`SortablePageParam`使用示例：**

```java
// 前端请求参数
{
    "pageNo": 1,
    "pageSize": 10,
    "sortingFields": [
        {"field": "createTime", "order": "DESC"},
        {"field": "id", "order": "ASC"}
    ],
    "entName": "测试企业"
}
```

#### 分页返回结果

**统一使用`PageResult<T>`：**

```java
// Service层返回
public PageResult<CustomerQuotaRespVO> getCustomerQuotaPage(CustomerQuotaPageReqVO pageReqVO) {
    PageResult<CustomerQuotaDO> pageResult = customerQuotaMapper.selectPage(pageReqVO);
    return BeanUtils.toBean(pageResult, CustomerQuotaRespVO.class);
}

// Controller层返回
public CommonResult<PageResult<CustomerQuotaRespVO>> getCustomerQuotaPage(
        @Valid CustomerQuotaPageReqVO pageReqVO) {
    PageResult<CustomerQuotaRespVO> pageResult = customerQuotaService.getCustomerQuotaPage(pageReqVO);
    return success(pageResult);
}
```

#### Mapper分页查询

**使用`BaseMapperX.selectPage()`方法：**

```java
@Mapper
public interface CustomerQuotaMapper extends BaseMapperX<CustomerQuotaDO> {
    
    default PageResult<CustomerQuotaDO> selectPage(CustomerQuotaPageReqVO reqVO) {
        return selectPage(reqVO, new LambdaQueryWrapperX<CustomerQuotaDO>()
                .likeIfPresent(CustomerQuotaDO::getEntName, reqVO.getEntName())
                .likeIfPresent(CustomerQuotaDO::getCreditCode, reqVO.getCreditCode())
                .eqIfPresent(CustomerQuotaDO::getStatus, reqVO.getStatus())
                .orderByDesc(CustomerQuotaDO::getId));
    }
}
```

**注意事项：**

- `pageSize = -1`表示不分页，返回全量数据
- 排序推荐使用`SortablePageParam`，由框架自动处理
- 禁止返回`IPage`或`Page`，必须转换为`PageResult`

### 1.7 异常处理规范

#### 业务异常抛出

**使用`ServiceException`或`ServiceExceptionUtil.exception()`：**

```java
@Service
public class CustomerQuotaServiceImpl implements CustomerQuotaService {
    
    private void validateCustomerQuotaExists(Long id) {
        if (customerQuotaMapper.selectById(id) == null) {
            throw exception(ErrorCodeConstants.CUSTOMER_QUOTA_NOT_EXISTS);
        }
    }
    
    // 或直接抛出
    if (duplicated) {
        throw new ServiceException(GlobalErrorCodeConstants.BAD_REQUEST.getCode(), "名称重复");
    }
}
```

#### 错误码定义

**在`ErrorCodeConstants`接口中定义：**

```java
package com.ahzx.tdcp.module.customer.enums;

import com.wmt.framework.common.exception.ErrorCode;

/**
 * Customer 错误码枚举类
 * <p>
 * customer 系统，使用 1-030-000-000 段
 */
public interface ErrorCodeConstants {
    
    // ========== 额度管理 1-030-001-000 ==========
    ErrorCode CUSTOMER_QUOTA_NOT_EXISTS = new ErrorCode(1_030_001_000, "客户额度不存在");
    
    // ========== 其他功能 1-030-002-000 ==========
    // ...
}
```

**错误码格式：`模块-子模块-功能-序号`**

- 模块：1-xxx（系统级）
- 子模块：1-030（customer模块）
- 功能：1-030-001（quota功能）
- 序号：1-030-001-000（具体错误）

#### 异常处理原则

1. **Controller层不捕获异常**：由全局异常处理器统一处理
2. **Service层抛出业务异常**：使用`ServiceException`
3. **禁止返回null**：无数据返回空集合或抛出异常
4. **禁止吞掉异常**：不要catch后不处理

```java
// ✅ 正确示例
@Override
public CustomerQuotaRespVO getCustomerQuota(Long id) {
    CustomerQuotaDO quota = customerQuotaMapper.selectById(id);
    if (quota == null) {
        throw exception(ErrorCodeConstants.CUSTOMER_QUOTA_NOT_EXISTS);
    }
    return BeanUtils.toBean(quota, CustomerQuotaRespVO.class);
}

// ❌ 错误示例
@Override
public CustomerQuotaRespVO getCustomerQuota(Long id) {
    CustomerQuotaDO quota = customerQuotaMapper.selectById(id);
    return quota == null ? null : BeanUtils.toBean(quota, CustomerQuotaRespVO.class);
}
```

## 三、架构规范

### 3.1 分层架构

#### 标准分层结构

```
Controller层（控制器层）
    ↓ 调用
Service层（服务层）
    ↓ 调用
Mapper层（数据访问层）
    ↓ 操作
Database（数据库）
```

#### 各层职责

| 层级 | 职责 | 禁止事项 |
|------|------|---------|
| **Controller** | 接收HTTP请求、参数校验、调用Service、返回CommonResult | 不包含业务逻辑、不直接操作数据库 |
| **Service** | 业务逻辑处理、事务管理、调用Mapper | 不直接操作数据库（通过Mapper） |
| **Mapper** | 数据访问、SQL执行 | 不包含业务逻辑 |
| **DO** | 数据对象、映射数据库表 | 不包含业务方法 |

---

### 3.2 VO/DTO/DO分离规范

#### 对象类型说明

| 类型 | 全称 | 用途 | 位置 | 示例 |
|------|------|------|------|------|
| **DO** | Data Object | 数据库实体，对应表结构 | `dal/dataobject` | `CustomerQuotaDO` |
| **VO** | View Object | 视图对象，用于前后端交互 | `controller/**/vo` | `CustomerQuotaRespVO` |
| **DTO** | Data Transfer Object | 数据传输对象（本项目较少使用） | - | - |

#### DO（数据对象）

```java

@EqualsAndHashCode(callSuper = true)
```

**特点：**

- 继承`BaseDO`（包含基础字段）
- 使用`@TableName`指定表名
- 字段与数据库表一一对应

#### 对象转换

**使用`BeanUtils.toBean()`进行转换：**


1. **DO不暴露给前端**：Controller层不直接返回DO

3. **字段映射**：DO和VO字段名保持一致，便于转换
4. **字段过滤**：VO只包含前端需要的字段

### 3.3 Mapper规范

#### Mapper接口定义

```java
@Mapper
public interface CustomerQuotaMapper extends BaseMapperX<CustomerQuotaDO> {
    // 自定义方法
}
```

**必须继承`BaseMapperX<T>`，提供以下方法：**

- `selectById(id)`：根据ID查询
- `selectList(wrapper)`：列表查询
- `selectPage(pageParam, wrapper)`：分页查询
- `insert(entity)`：插入
- `updateById(entity)`：根据ID更新
- `deleteById(id)`：根据ID删除（逻辑删除）

#### 分页查询方法

```java
@Mapper
public interface CustomerQuotaMapper extends BaseMapperX<CustomerQuotaDO> {
    
    default PageResult<CustomerQuotaDO> selectPage(CustomerQuotaPageReqVO reqVO) {
        return selectPage(reqVO, new LambdaQueryWrapperX<CustomerQuotaDO>()
                .likeIfPresent(CustomerQuotaDO::getEntName, reqVO.getEntName())
                .likeIfPresent(CustomerQuotaDO::getCreditCode, reqVO.getCreditCode())
                .eqIfPresent(CustomerQuotaDO::getStatus, reqVO.getStatus())
                .orderByDesc(CustomerQuotaDO::getId));
    }
}
```

**使用`LambdaQueryWrapperX`构建查询条件：**

- `likeIfPresent`：模糊查询（值不为空时）
- `eqIfPresent`：等值查询（值不为空时）
- `inIfPresent`：IN查询（值不为空时）
- `betweenIfPresent`：范围查询（值不为空时）
- `orderByDesc`、`orderByAsc`：排序

#### 条件构造器使用

```java
// 等值查询
.eq(CustomerQuotaDO::getStatus, "0")

// 模糊查询
.like(CustomerQuotaDO::getEntName, "测试")

// IN查询
.in(CustomerQuotaDO::getId, Arrays.asList(1L, 2L, 3L))

// 范围查询
.between(CustomerQuotaDO::getCreateTime, startTime, endTime)

// 排序
.orderByDesc(CustomerQuotaDO::getCreateTime)
.orderByAsc(CustomerQuotaDO::getId)

// 组合条件
.and(wrapper -> wrapper
    .eq(CustomerQuotaDO::getStatus, "0")
    .or()
    .eq(CustomerQuotaDO::getStatus, "1")
)
```

#### 禁止事项

1. **禁止手写SQL**：优先使用Wrapper构建条件
2. **禁止返回IPage**：必须返回`PageResult`
3. **禁止在Mapper中包含业务逻辑**：只负责数据访问

```java
        customerQuotaMapper.insert(quota);
        // 返回
        return quota.getId();
    }
    
    @Override
    public void updateCustomerQuota(CustomerQuotaSaveReqVO updateReqVO) {
        // 校验存在
        validateCustomerQuotaExists(updateReqVO.getId());
        // 更新
        CustomerQuotaDO updateObj = BeanUtils.toBean(updateReqVO, CustomerQuotaDO.class);
        customerQuotaMapper.updateById(updateObj);
    }
    
    @Override
    public void deleteCustomerQuota(Long id) {
        // 校验存在
        validateCustomerQuotaExists(id);
        // 删除（逻辑删除）
        customerQuotaMapper.deleteById(id);
    }
    
    private void validateCustomerQuotaExists(Long id) {
        if (customerQuotaMapper.selectById(id) == null) {
            throw exception(ErrorCodeConstants.CUSTOMER_QUOTA_NOT_EXISTS);
        }
    }
    
    @Override
    public CustomerQuotaRespVO getCustomerQuota(Long id) {
        CustomerQuotaDO quota = customerQuotaMapper.selectById(id);
        if (quota == null) {
            return null;  // 或抛出异常
        }
        return BeanUtils.toBean(quota, CustomerQuotaRespVO.class);
    }
    
    @Override
    public PageResult<CustomerQuotaRespVO> getCustomerQuotaPage(CustomerQuotaPageReqVO pageReqVO) {
        PageResult<CustomerQuotaDO> pageResult = customerQuotaMapper.selectPage(pageReqVO);
        return BeanUtils.toBean(pageResult, CustomerQuotaRespVO.class);
    }
}
```

#### Service层规范

1. **接口与实现分离**：定义接口，实现类实现接口
2. **参数校验**：使用`@Validated`和`@Valid`
3. **异常处理**：业务异常使用`ServiceException`抛出

5. **返回类型**：创建返回`Long`（ID），更新/删除返回`void`，查询返回对象或`PageResult`

### 4.7 事务管理规范

#### 事务注解使用

```java
@Service
public class CustomerQuotaServiceImpl implements CustomerQuotaService {
    
    @Transactional(rollbackFor = Exception.class)
    @Override
    public Long createCustomerQuota(CustomerQuotaSaveReqVO createReqVO) {
        // 业务逻辑
    }
}
```

#### 事务传播行为

| 传播行为 | 说明 | 使用场景 |
|---------|------|---------|
| `REQUIRED`（默认） | 如果当前存在事务，则加入该事务；如果当前不存在事务，则创建一个新的事务 | 大多数场景 |
| `REQUIRES_NEW` | 创建一个新的事务，如果当前存在事务，则把当前事务挂起 | 独立事务场景 |
| `SUPPORTS` | 如果当前存在事务，则加入该事务；如果当前不存在事务，则以非事务的方式继续运行 | 查询方法 |

#### 事务隔离级别

| 隔离级别 | 说明 | 使用场景 |
|---------|------|---------|
| `READ_UNCOMMITTED` | 读未提交 | 不推荐 |
| `READ_COMMITTED`（默认） | 读已提交 | 大多数场景 |
| `REPEATABLE_READ` | 可重复读 | MySQL默认 |
| `SERIALIZABLE` | 串行化 | 高一致性要求 |

#### 事务注意事项

1. **异常回滚**：使用`rollbackFor = Exception.class`确保所有异常都回滚
2. **事务范围**：事务方法不要调用同类其他方法（避免代理失效）
3. **查询方法**：查询方法一般不需要事务

### C. 常见问题

#### Q1: Controller方法返回类型必须是CommonResult吗？

**A:** 是的，所有Controller方法必须返回`CommonResult<T>`，这是框架的统一规范。

#### Q2: 分页查询必须使用SortablePageParam吗？

**A:** 不是必须的，可以使用`PageParam`（不支持排序）或`SortablePageParam`（支持排序），推荐使用`SortablePageParam`。

#### Q3: Mapper必须继承BaseMapperX吗？

**A:** 是的，必须继承`BaseMapperX<T>`，这样才能使用框架提供的分页等功能。

#### Q4: Service层需要事务注解吗？

**A:** 需要事务的方法（如创建、更新、删除）应该使用`@Transactional`，查询方法一般不需要。

#### Q5: 错误码如何定义？

**A:** 在模块的`ErrorCodeConstants`接口中定义，格式为`模块-子模块-功能-序号`。
