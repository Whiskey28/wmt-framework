# WMT Framework 业务系统部署规范规划

## 📋 规划概述

本文档规划了基于 WMT Framework 的业务系统的三种部署方式规范：
1. **二进制部署**：传统 JAR 包直接部署
2. **Docker 容器化部署**：基于 Docker 的单机/多机部署
3. **Kubernetes 部署**：基于 K8s 的云原生部署

---

## 🎯 一、部署规范涉及的核心要点

### 1.1 环境准备与要求

#### 1.1.1 基础环境
- [ ] **JDK 版本要求**
  - 最低版本：JDK 8
  - 推荐版本：JDK 8 / JDK 11 / JDK 17
  - 版本兼容性说明
  - 环境变量配置（JAVA_HOME、PATH）

- [ ] **操作系统要求**
  - Linux（CentOS 7+、Ubuntu 18.04+、Alpine）
  - Windows Server（可选）
  - 系统资源要求（CPU、内存、磁盘）

- [ ] **网络要求**
  - 端口规划与开放规则
  - 防火墙配置
  - 内网/外网访问策略

#### 1.1.2 中间件环境
- [ ] **数据库（MySQL/PostgreSQL/Oracle）**
  - 版本要求（MySQL 5.7+ / 8.0+）
  - 字符集配置（UTF8MB4）
  - 连接池配置
  - 数据库初始化脚本
  - 备份与恢复策略

- [ ] **Redis**
  - 版本要求（Redis 3.0+，推荐 6.x/7.x）
  - 单机/集群模式
  - 持久化配置（RDB/AOF）
  - 密码认证配置
  - 内存规划

- [ ] **消息队列（可选）**
  - RocketMQ：版本要求、NameServer、Broker 配置
  - RabbitMQ：版本要求、集群配置
  - Kafka：版本要求、Zookeeper 配置

- [ ] **其他中间件（可选）**
  - Elasticsearch（搜索场景）
  - XXL-Job（定时任务调度中心）
  - Flowable（工作流引擎）
  - Nacos/Consul（服务注册与配置中心）

#### 1.1.3 监控与日志
- [ ] **监控组件**
  - Prometheus + Grafana
  - SkyWalking（链路追踪）
  - Spring Boot Actuator

- [ ] **日志组件**
  - ELK Stack（Elasticsearch + Logstash + Kibana）
  - 日志文件存储策略
  - 日志轮转配置

- [ ] **Maven 构建配置**
  - 构建命令规范
  - 打包配置（JAR/WAR）

- [ ] **配置文件结构**
  - `application.yml`（基础配置）
  - `application-{profile}.yml`（环境配置）
  - 外部配置文件支持

- [ ] **配置项分类**
  - 数据库连接配置
  - Redis 配置

### 1.4 部署目录结构

- [ ] **标准目录结构**
  ```
  /opt/apps/{app-name}/
  ├── bin/              # 启动/停止脚本
  ├── config/           # 配置文件
  ├── lib/              # JAR 包依赖
  ├── logs/             # 日志文件
  ├── data/             # 数据文件（可选）
  └── temp/             # 临时文件
  ```

- [ ] **目录权限管理**
  - 用户与用户组设置
  - 目录权限规范（755/750）
  - 日志目录权限
