## 欧洲市场（Hades）

### 📊 快速诊断（5分钟）
- 现金/盈利：本回合净利 48,242；EBIT 63,505；现金 63,779（净现金，安全）。
- 技术1：149 EUR，功能5，销量=需求 1,029k；销售额 220,785；成本 220,685；广告 25,000；毛利 -24,901 → 成本≈售价，广告后大亏。
- 技术2：388 EUR，功能5，销量=需求 430k；销售额 239,983；成本 126,578；广告 15,000；毛利 98,406 → 高毛利、高满足率。
- 结论：技2是利润核心；技1需止血（提价/减广/降成本）。

### 📈 详细分析（30分钟）
#### 2.1 财务分析
- 技1：成本率≈100%，广告后亏 24.9k；广告ROI为负。  
- 技2：成本率≈52.8%，广告后毛利 98.4k；销售利润率约 41%。  
- 整体盈利依赖技2；技1拖累显著。

#### 2.2 市场分析
- 技1：低价但仍亏，功能与均值相当，缺乏盈利空间；需差异化或提价止亏。  
- 技2：高价仍满销，竞争压力可控，具备提量/提价弹性；可通过小幅加广放量。  
- 满足率：两项均为100%，无缺货。

#### 2.3 成本分析
- 技1：进口+运税+功能成本叠加，导致成本≈售价；广告放大亏损。  
- 技2：成本结构良好，关键是维持低成本率同时放大销量。  

#### 2.4 生产分析
- 当前供需匹配；若要放大技2销量，需确认产能/供应链弹性；技1提价回落可释放产能给技2。

### 🎯 决策制定（15分钟）
#### 3.1 价格-功能-广告
- 技术1（防守/收缩）  
  - 价格：上调至 170-180 EUR（或更高以覆盖成本）。  
  - 功能：维持5；可小范围试降到4以降成本。  
  - 广告：25,000 → 5,000-10,000；先压投入止亏。  
  - 目标：止血，接受份额下滑。  
- 技术2（重点进攻）  
  - 价格：维持 388；若提量可试 370-380（毛利率>40%才执行）。  
  - 功能：维持5。  
  - 广告：15,000 → 20,000-25,000，小步试 ROI>2 再考虑上限 30,000。  
  - 目标：销量 430k → 500-600k，保持高毛利率。  

#### 3.2 资源分配
- 广告：大幅削技1，适度加技2；净广告不必大增，护现金。  
- 产能：优先保障技2；技1提价后释放的产能供技2。  

#### 3.3 风险与验证
- 技1提价/减广导致份额下降：可接受，只要止亏；如仍亏再收缩。  
- 技2降价/加广：若毛利率<40%或 ROI<1.5，立即回撤。  

### ✅ 行动清单（欧洲）
- 技1：价 170-180；广 5k-10k；功能5（或试降4）；观察盈亏弹性。  
- 技2：价 388（或试 370-380 小步）；广 20k-25k 试水；功能5；跟踪毛利率/ROI。  
- 复盘指标：技1盈亏与销量弹性；技2毛利率、ROI、销量增量。

## 亚洲市场（Hades）

**用户确认数据：** 技术2 功能=3，售价=2,599 RMB，销量/需求=344k，销售额=3,172；广告=8,000；毛利≈-7,521（推算成本≈2,693）。  
技1数据：售价 1,650 RMB，功能4，销量/需求 2,494k；销售额≈508,133；成本≈514,403；广告 30,000；毛利≈-36,270。

### 📊 快速诊断（5分钟）
- 整体：本回合净利 5,190；现金 63,779（安全但边际薄）。  
- 技术1：成本率>100%，广告后大亏。  
- 技术2：成本率≈85%，广告后小亏；满足率100%。  
- 结论：技1是主要亏损点；技2亏损较小，可优化后投入。

### 📈 详细分析（30分钟）
#### 2.1 财务分析
- 技1：成本>售价，广告放大亏损，需提价/减广/降成本。  
- 技2：销售额 3,172，成本约 2,693，广告 8,000，毛利 -7,521；若提价/提量或降成本，可转正。  

#### 2.2 市场分析
- 技1：低价低功能仍亏，表明成本失衡；需提价或显著减投。  
- 技2：高价（2,599）+低广告（8k）+功能3；若有更大潜在需求，需从价格/广告/供给三方面组合优化。  
- 满足率：技1、技2均100%；若需求真实更大，当前供给可能限制了销量。  

#### 2.3 成本分析
- 技1：进口+运税+功能成本叠加，广告再放大亏损；需要本地化/降功能/提价。  
- 技2：成本可控，小亏主要因广告+价格/销量组合；慎重增加功能以免抬成本。  

#### 2.4 生产分析
- 技1满足率100%，提价后销量回落可接受。  
- 技2满足率100%，若市场更大需确认产能/供货，再考虑提量。  

### 🎯 决策制定（15分钟）
#### 3.1 价格-功能-广告
- 技术1（止血优先）  
  - 价格：上调至 1,750-1,850 RMB；若坚持 1,650，必须大幅减广。  
  - 功能：维持4，或试点降到3以降成本。  
  - 广告：30,000 → 5,000-10,000；先压投入，观察ROI。  
  - 目标：快速止亏，接受份额下滑。  
- 技术2（优化投入）  
  - 价格：维持 2,599；如需提量可试 2,450-2,520，确保毛利率>35-40%。  
  - 功能：维持3（谨慎加功能，避免成本抬升）。  
  - 广告：8,000 → 10,000-15,000 小步试水；ROI>2 再考虑 15,000-20,000。  
  - 目标：扭亏为盈，提升销量/份额，同时保持正毛利和合理ROI。  

#### 3.2 资源分配
- 广告：削技1 20k-25k，小幅增技2 2k-7k；净降广告，护现金。  
- 产能：优先保障技2；技1提价回落释放的产能补给技2。  

#### 3.3 风险与验证
- 技1提价/减广导致份额下降：可接受，只要止亏；仍亏则继续收缩。  
- 技2小降价/加广：若毛利率<35%或ROI<1.5，立即回撤。  
- 数据敏感：如后续有更精确的需求/成本，请再校正，以便精算价格-广告-毛利敏感区间。  

### ✅ 行动清单（亚洲）
- 技1：价 1,750-1,850；广 5k-10k；功能4(或3试点)；先止亏。
