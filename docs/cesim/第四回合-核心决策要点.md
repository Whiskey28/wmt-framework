## 💊 核心策略：稳中求进

### 策略原则

```
1. 现金流优先：现金流 > 利润 > 增长
2. 聚焦核心：1-2个市场，1-2个产品
3. 成本领先：暂时放弃差异化，通过成本优势竞争
4. 稳中求进：先活下来，再考虑追赶
```

## ⚡ 立即执行的5个决策

### 决策1：计算现金流状况

```
可用资金 = 当前现金 - 最低现金要求 - 短期贷款到期

判断：
✅ > 100,000 → 可以适度投入
⚠️ 0-100,000 → 紧急收缩
❌ < 0 → 立即贷款或大幅削减
```

---

### 决策2：选择核心市场（聚焦1-2个）

**优先级排序：**
1. **利润 > 0** 且 **现金周转快** = 优先级1（重点保留）
2. **利润 > 0** 但 **现金周转慢** = 优先级2（适度保留）
3. **利润 < 0** 但 **有改善希望** = 优先级3（收缩或退出）
4. **利润 < 0** 且 **无改善希望** = 优先级4（立即退出）

**建议：只保留优先级1-2的市场和技术**

---

### 决策3：削减支出（立即执行）

```
研发投入：削减至 50,000 以下（仅维持现有技术）
广告投入：削减至 60,000-100,000（聚焦核心市场）
工厂建设：暂停（需要两回合才生效）

预计节省：150,000 - 300,000 千USD
```

---

### 决策4：价格策略（保证最低利润率）

```
最低价格 = 单位成本 × 1.20（20%利润率）

如果库存积压：适度降价（但必须 > 最低价格），快速销售
如果竞争激烈：接近市场平均价格，但不打价格战
如果有成本优势：可以适度降价，获得销量优势

关键：必须保证最低利润率20%以上
```

---

### 决策5：产品策略（减少功能，降低成本）

```
功能成本 = 功能数 × 6 USD/功能/件

如果功能成本高：减少功能数，降低成本
如果竞争激烈：功能 = 市场平均 - 1（成本领先）
如果现金流紧张：减少功能，降低成本

减少1个功能，每1000件节省6,000 USD
```

## ⚠️ 必须避免的错误

1. **不要急于追赶：** 落后20个百分点是事实，不要试图一回合追回
2. **不要打价格战：** 如果对手大幅降价，考虑退出或收缩，不要硬拼
3. **不要分散资源：** 聚焦1-2个核心市场，不要试图所有市场都做
4. **不要过度贷款：** 只借必要的最低额度，避免财务费用过高
5. **不要停止核心产品：** 即使利润低，也要保留能产生现金的产品

3. **无法差异化：** 暂时放弃，通过成本优势竞争
4. **可能需要3-4回合才能恢复：** 要有耐心，稳中求进
