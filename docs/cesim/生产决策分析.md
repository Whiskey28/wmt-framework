## 二、决策模型

### 2.1 总成本对比

**在美国生产并销往欧洲：**
```
总成本 = 美国生产成本 + 运输关税(12 USD)
```

**在亚洲生产并销往欧洲：**
```
总成本 = 亚洲生产成本 + 运输关税(8 USD)
```

### 2.2 临界点分析

**选择美国生产的条件：**
```
美国生产成本 + 12 < 亚洲生产成本 + 8
即：美国生产成本 < 亚洲生产成本 - 4
```

**选择亚洲生产的条件：**
```
美国生产成本 + 12 > 亚洲生产成本 + 8
即：美国生产成本 > 亚洲生产成本 - 4
```

**关键发现：**
- 亚洲运输成本比美国低**4 USD/件**
- 如果亚洲生产成本比美国高**4 USD以内**，选择亚洲更经济
- 如果亚洲生产成本比美国高**超过4 USD**，选择美国更经济
