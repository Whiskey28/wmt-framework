## 🎯 核心思路

### 三步走战略

```
第一步：快速诊断（5分钟）
    ↓ 判断当前状况
第二步：详细分析（30分钟）
    ↓ 深入分析各维度
第三步：决策制定（15分钟）
    ↓ 制定具体策略
```

### 五维分析框架

1. **财务分析** → 现金流、盈利能力、风险
2. **市场分析** → 机会识别、竞争态势、策略组合
3. **成本分析** → 成本结构、优化机会
4. **生产分析** → 产能、生产决策
5. **综合决策** → 评分卡、资源分配、策略制定

## 📊 关键分析工具

### 1. 快速诊断工具

**现金流检查：**
```
可用资金 = 现金 - 最低现金要求 - 短期贷款到期
✅ >200,000 → 可以激进
⚠️ 100,000-200,000 → 谨慎投入
❌ <100,000 → 防守为主
```

**盈利能力检查：**
```
净利润排名：
✅ 前3名 → 可以加大投入
⚠️ 中游 → 稳中求进
❌ 后3名 → 必须改变策略
```

### 2. 市场机会识别工具

**优先级评分表：**

| 市场 | 技术 | 需求增长 | 竞争强度 | 你的份额 | 总分 | 决策 |
|------|------|----------|----------|----------|------|------|
| ? | ? | >20%=10分<br>10-20%=7分<br><10%=5分 | 低=10分<br>中=6分<br>高=3分 | >15%=10分<br>10-15%=7分<br><10%=5分 | 平均分 | >7=重点<br>5-7=适度<br><5=防守 |

### 3. 决策评分卡

**评分维度：**

| 维度 | 权重 | 说明 |
|------|------|------|
| 市场层面利润 | 25% | 盈利能力 |
| 需求增长潜力 | 20% | 市场机会 |
| 竞争强度 | 20% | 竞争环境（低分好） |
| 你的竞争优势 | 15% | 差异化能力 |
| 资源投入效率 | 10% | 投入产出比 |
| 战略重要性 | 10% | 长期价值 |

**总分 > 7：重点投入**
**总分 5-7：适度投入**
**总分 < 5：防守或退出**

### 4. 价格-功能-广告决策规则

**价格决策：**
- 成本优势明显 → 比市场平均低10-15%
- 功能优势明显 → 比市场平均高5-10%
- 竞争激烈 → 接近市场平均

**功能决策：**
- 竞争激烈 → 功能 ≥ 市场平均
- 成本敏感 → 功能 = 市场平均 - 1
- 差异化 → 功能 = 市场平均 + 1-2

**广告决策：**
- 抢占市场 → 市场平均 × 1.2-1.5
- 防守 → 市场平均 × 0.8-1.0
- 现金流紧张 → 市场平均 × 0.5-0.8

## 🎲 邪修技巧总结

### 1. 转移定价利用
- 识别转移定价影响
- 计算真实市场层面利润
- 参考：[真实盈利能力分析方法.md](./真实盈利能力分析方法.md)

### 2. 对手财务压力利用
- 识别现金流紧张的对手
- 在其重点市场加大投入
- 迫使其退出

### 3. 需求预测利用
- 提前布局高增长市场（需求增长>20%）
- 抢占先机，建立壁垒

### 4. 成本结构优化
- 自身生产 vs 外包（选择更便宜的）
- 本地生产 vs 运输（考虑运输成本）
- 功能数优化（减少不必要功能）

### 5. 差异化定位
- 避开红海（竞争强度>4）
- 寻找竞争空白（竞争强度<3）
- 高功能+高价格 或 低功能+低价格

### 6. 长期战略布局
- 提前建设工厂（如亚洲工厂第三回合投产）
- 提前研发技术（技术3/4提前布局）
- 建立成本优势（规模效应）

## 📈 关键数字记忆

### 成本参数
- 单位功能成本：**6 USD/功能/件**
- 运输关税：美国→亚洲**27 USD/件**，美国→欧洲**12 USD/件**
- 最低现金要求：通常**6,000千USD**

### 判断标准
- 现金流安全线：**100,000千USD**
- 市场份额健康线：**10%**
- 利润率健康线：**30%**
- 竞争强度：**<3低，3-4中，>4高**

### 决策阈值
- 需求增长高：**>20%**
- 需求增长中：**10-20%**
- 需求增长低：**<10%**
- 价格竞争力：**±10%**
- 功能竞争力：**±1**
