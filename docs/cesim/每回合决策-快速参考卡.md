# 每回合决策 - 快速参考卡
## 5分钟快速诊断 + 关键决策规则

---

## 🚨 第一步：快速诊断（5分钟）

### 现金流检查（最重要！）

```
可用资金 = 现金 - 最低现金要求 - 短期贷款到期

✅ >200,000 → 可以激进
⚠️ 100,000-200,000 → 谨慎投入
❌ <100,000 → 防守为主
```

### 盈利能力检查

```
净利润排名：
✅ 前3名 → 可以加大投入
⚠️ 中游 → 稳中求进
❌ 后3名 → 必须改变策略
```

### 市场份额检查

```
各市场各技术：
✅ 都在10%以上 → 健康
⚠️ 有低于5%的 → 危险
❌ 全面下降 → 紧急调整
```

## 📊 第二步：市场机会识别（快速版）

### 优先级评分（1-10分）

| 市场 | 技术 | 需求增长 | 竞争强度 | 你的份额 | 总分 | 决策 |
|------|------|----------|----------|----------|------|------|
| ? | ? | >20%=10分<br>10-20%=7分<br><10%=5分 | 低=10分<br>中=6分<br>高=3分 | >15%=10分<br>10-15%=7分<br><10%=5分 | 平均分 | >7=重点<br>5-7=适度<br><5=防守 |

**快速规则：**
- 需求增长>20% + 竞争强度低 = 极高优先级
- 需求增长<10% + 竞争强度高 = 低优先级或退出

---

## 💰 第三步：价格-功能-广告决策（快速版）

### 价格决策

```
成本优势明显 → 比市场平均低10-15%
功能优势明显 → 比市场平均高5-10%
竞争激烈 → 接近市场平均
```

### 功能决策

```
竞争激烈 → 功能 ≥ 市场平均
成本敏感 → 功能 = 市场平均 - 1
差异化 → 功能 = 市场平均 + 1-2
```

### 广告决策

```
抢占市场 → 市场平均 × 1.2-1.5
防守 → 市场平均 × 0.8-1.0
现金流紧张 → 市场平均 × 0.5-0.8
```

---

## 🎯 第四步：资源分配优先级

### 优先级排序规则

1. **高利润 + 高增长 + 低竞争** = 最高优先级
2. **高利润 + 中增长 + 中竞争** = 高优先级
3. **中利润 + 高增长 + 低竞争** = 中高优先级
4. **中利润 + 中增长 + 中竞争** = 中优先级
5. **低利润 + 低增长 + 高竞争** = 低优先级或退出

### 资源分配比例

```
最高优先级：40-50%资源
高优先级：25-30%资源
中优先级：15-20%资源
低优先级：5-10%资源或退出
```

## ⚡ 邪修技巧（快速版）

### 1. 转移定价识别
- 单位成本偏离市场平均>±20% → 可能转移定价
- 跨市场利润率差异>±15% → 可能转移定价

### 2. 对手财务压力利用
- 识别现金流紧张的对手
- 在其重点市场加大投入
- 迫使其退出

### 3. 需求预测利用
- 提前布局高增长市场（需求增长>20%）
- 抢占先机，建立壁垒

### 4. 成本结构优化
- 自身生产 vs 外包（选择更便宜的）
- 本地生产 vs 运输（考虑运输成本）
- 功能数优化（减少不必要功能）

### 5. 差异化定位
- 避开红海（竞争强度>4）
- 寻找竞争空白（竞争强度<3）
- 高功能+高价格 或 低功能+低价格

## 🎲 常见场景快速决策

### 场景1：现金流紧张

**策略：** 防守为主
- 减少广告投入（市场平均×0.5-0.8）
- 减少功能投入（市场平均-1）
- 优先高利润组合
- 考虑退出低利润组合

### 场景2：排名后3

**策略：** 差异化+聚焦
- 避开高竞争市场
- 寻找竞争空白
- 聚焦1-2个高增长市场
- 加大投入，快速抢占

### 场景3：排名前3

**策略：** 稳中求进
- 保持优势市场
- 适度扩张
- 提前布局长期战略
- 防范对手反击

### 场景4：高增长市场出现

**策略：** 快速抢占
- 提前布局（需求增长>20%）
- 加大投入（广告×1.2-1.5）
- 建立先发优势
- 快速建立壁垒

## 📌 关键数字记忆

### 成本参数
- 单位功能成本：**6 USD/功能/件**
- 运输关税：美国→亚洲**27 USD/件**，美国→欧洲**12 USD/件**
- 最低现金要求：通常**6,000千USD**（三个市场各2,000）

### 判断标准
- 现金流安全线：**100,000千USD**
- 市场份额健康线：**10%**
- 利润率健康线：**30%**
- 竞争强度：**<3低，3-4中，>4高**

### 决策阈值
- 需求增长高：**>20%**
- 需求增长中：**10-20%**
- 需求增长低：**<10%**
- 价格竞争力：**±10%**
- 功能竞争力：**±1**

```

5. 决策验证（5分钟）
   └─ 现金流、利润、风险验证
```
