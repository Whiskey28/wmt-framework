### 2.2 分析指标计算

#### A. 盈利能力指标

1. **销售利润率** = 销售利润 / 销售额
2. **毛利率** = 毛利 / 销售额
3. **单位贡献利润** = (销售额 - 单位成本) / 销量
4. **广告ROI** = 毛利 / 广告投入

#### B. 市场效率指标

1. **市场份额** = 销量 / 市场总需求
2. **市场份额变化** = 第二回合份额 - 第一回合份额
3. **需求满足率** = 销量 / 需求（是否供不应求）
4. **价格竞争力** = (市场平均价格 - 你的价格) / 市场平均价格

#### C. 投入产出效率

1. **广告效率** = 销量增量 / 广告投入（如果有上回合数据）
2. **功能效率** = 销量 / 功能数量（功能对销量的贡献）
3. **价格弹性** = (销量变化% / 价格变化%) 的绝对值
