## 二、分析模型设计

### 2.1 成本-收益分析模型

#### 目标
计算每个"市场×技术"组合的单位经济模型，识别最赚钱的组合。

#### 关键指标
1. **单位贡献利润** = 售价 - 单位总成本
2. **单位总成本** = 生产成本 + 功能成本 + 运输关税 + 分摊广告成本 + 分摊管理成本
3. **贡献利润率** = 单位贡献利润 / 售价
4. **盈亏平衡销量** = 固定成本 / 单位贡献利润
5. **目标销量下的总贡献利润**

#### 数据需求
- 各市场各技术的售价（从市场报告提取）
- 各市场各技术的销量（从市场报告提取）
- 生产成本（自身生产+外包生产）
- 功能成本（功能数 × 6 USD/功能/件）
- 运输和关税（根据市场流向计算）
- 广告投入（从市场报告提取）
- 管理成本（固定+可变）

### 2.2 市场机会评估模型

#### 目标
评估各市场各技术的需求增长潜力、竞争强度、你的份额提升空间。

#### 关键指标
1. **需求增长率** = (本回合预测需求 - 上回合需求) / 上回合需求
2. **市场规模** = 本回合预测需求
3. **竞争强度评分** (1-5分)
   - 1分 = 蓝海，机会大
   - 2分 = 竞争温和
   - 3分 = 竞争正常
   - 4分 = 竞争激烈
   - 5分 = 红海，避免进入
4. **你的份额潜力** = 基于价格/功能/广告组合的预期份额

#### 数据需求
- 上回合各市场各技术的需求
- 本回合各市场各技术的需求预测
- 对手的价格、功能、广告策略
- 你的上回合市场份额

### 2.3 竞争态势分析模型

#### 目标
分析对手策略模式，识别差异化机会。

#### 关键指标
1. **对手策略分类**
   - 激进型：高功能+高广告+低价格
   - 保守型：中功能+中广告+中价格
   - 差异化型：高功能+高价格+中广告
   - 跟随型：模仿领先者

2. **价格竞争力** = 你的价格 vs 市场平均价格
3. **功能竞争力** = 你的功能数 vs 市场平均功能数
4. **广告竞争力** = 你的广告投入 vs 市场平均广告投入
5. **综合竞争力评分** = f(价格、功能、广告、市场份额)

#### 数据需求
- 所有对手在各市场各技术的价格、功能、广告、市场份额
- 市场平均价格、功能、广告水平

### 2.4 资源约束与优化模型

#### 目标
在资源约束下，优化资源分配，最大化累计股东回报率。

#### 关键约束
1. **现金流约束**: 可用现金 + 可贷款额度
2. **生产能力约束**: 美国12厂产能，亚洲3厂（第三回合可用）
3. **研发约束**: 技术1/2功能上限10，技术3/4研发周期
4. **市场选择约束**: 每市场最多2种技术

#### 优化目标
最大化 = Σ(各市场各技术的贡献利润) - 固定成本 - 财务费用

#### 决策变量
- 各市场各技术的价格、功能、广告
- 各市场各技术的产量/销量目标
- 研发投入分配

#### 输出
- 最优资源分配方案
- 预期收益和风险
- 现金流预测

### 2.5 决策评分卡模型

#### 目标
为每个"市场×技术"组合打分，量化评估优先级。

#### 评分维度（权重）
1. **单位贡献利润** (25%) - 盈利能力
2. **需求增长潜力** (20%) - 市场机会
3. **竞争强度** (20%，低分好) - 竞争环境
4. **你的竞争优势** (15%) - 差异化能力
5. **资源投入效率** (10%) - 投入产出比
6. **战略重要性** (10%) - 长期价值

#### 评分标准
每个维度1-10分，加权求和得到总分。

## 三、分析流程

### 3.1 数据提取与清洗
1. 从CSV提取各市场各技术的价格、功能、广告、销量数据
2. 提取成本数据（生产成本、功能成本、运输关税）
3. 提取对手数据（价格、功能、广告、市场份额）
4. 数据清洗和标准化

### 3.2 成本-收益分析
1. 计算各"市场×技术"组合的单位成本结构
2. 计算单位贡献利润和贡献利润率
3. 识别高利润组合和亏损组合
4. 分析广告效率（ROI）

### 3.3 市场机会评估
1. 评估各市场各技术的需求增长潜力
2. 评估竞争强度
3. 评估你的份额提升潜力
4. 识别竞争空白和机会窗口

### 3.4 竞争态势分析
1. 分析对手策略模式
2. 评估你的竞争力（价格、功能、广告）
3. 识别差异化机会
4. 预测对手可能的策略变化

### 3.5 资源分配优化
1. 列出资源约束
2. 设计多个资源分配方案
3. 评估各方案的预期收益和风险
4. 选择最优方案

### 3.6 决策评分与建议
1. 使用决策评分卡为各组合打分
2. 根据评分排序，确定优先级
3. 给出具体策略建议（价格、功能、广告、市场选择）
