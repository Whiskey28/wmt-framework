### 1.2 计算指标

#### A. 盈利能力指标
- 销售利润率 = 销售利润 / 销售额
- 毛利率 = 毛利 / 销售额  
- 单位贡献利润 = 销售利润 / 销量
- 广告ROI = 毛利 / 广告投入

#### B. 市场指标
- 市场份额 = 销量 / 市场总需求
- 市场份额变化 = 第二回合份额 - 第一回合份额
- 需求满足率 = 销量 / 需求

#### C. 竞争力指标
- 价格竞争力 = (市场平均价格 - 你的价格) / 市场平均价格
- 功能竞争力 = 你的功能数 - 市场平均功能数

---

### 1.3 成功方案识别标准

**综合评分 = 毛利排名(30%) + 市场份额排名(25%) + 广告ROI排名(20%) + 销售利润率排名(15%) + 市场份额增长(10%)**

### 1.4 第三回合预测方法

- 功能趋势：判断是否继续"军备竞赛"
