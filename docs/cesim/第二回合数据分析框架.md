## 二、关键指标计算

### 2.1 财务健康度指标

```
可用资金 = 现金 - 最低现金要求(6,000) - 短期贷款到期

现金流健康度：
✅ >200,000 → 可以激进
⚠️ 100,000-200,000 → 谨慎投入
❌ <100,000 → 防守为主
```

### 2.2 盈利能力指标

```
销售利润率 = 销售利润 / 销售额
毛利率 = 毛利 / 销售额
广告ROI = 毛利 / 广告投入
单位贡献利润 = 销售利润 / 销量
```

### 2.3 市场指标

```
市场份额 = 销量 / 市场总需求
市场份额变化 = 第二回合份额 - 第一回合份额
需求满足率 = 销量 / 需求
```

### 2.4 竞争力指标

```
价格竞争力 = (市场平均价格 - 你的价格) / 市场平均价格
功能竞争力 = 你的功能 - 市场平均功能
广告竞争力 = (你的广告 - 市场平均广告) / 市场平均广告
```
