## 三、数据提取规则

### 3.1 公司列索引

```python
TEAM_NAMES = [
    '万物生长ING',      # 列索引 1
    '津门创赋奇谭',     # 列索引 2
    '虚怀若谷',         # 列索引 3
    'Hades',           # 列索引 4 ⭐
    '从容应队',         # 列索引 5
    '高雅人士队',       # 列索引 6
    'PHY柿柿如意',      # 列索引 7
    '"烽"狂输出队',     # 列索引 8
    '决策全都队',       # 列索引 9
    '星河万里'          # 列索引 10
]

HADES_COL = 4  # Hades在第5列（索引从1开始，但pandas索引从0开始，所以是列索引3）
```

### 3.2 数据提取方法

1. **读取Excel**：使用pandas读取，header=None
2. **查找指标**：在第一列（索引0）中搜索指标名称
3. **提取数据**：从对应行的第二列开始提取各公司数据
4. **数据处理**：转换为数值类型，处理空值
