# 排障手册

## 1. 启动报 Bean 冲突

现象：
- 启动时报 `NoUniqueBeanDefinitionException` 或自动配置冲突

处理建议：
- 检查是否重复引入同类 starter
- 检查是否手工声明了与自动配置冲突的 Bean
- 对必要 Bean 使用 `@Primary` 或限定注入

## 2. 鉴权失败（401/403）

现象：
- 登录后访问接口仍返回未认证/无权限

处理建议：
- 确认 Token 是否正确透传
- 确认接口权限标识与角色权限映射
- 检查白名单配置是否覆盖登录接口

## 3. 数据源或事务异常

现象：
- 事务不生效、路由到错误数据源

处理建议：
- 检查动态数据源主库配置
- 检查事务注解层级与代理生效路径
- 避免在同类内部方法直接调用事务方法

## 4. WebSocket 无法连接

现象：
- 握手失败或连接建立后无消息

处理建议：
- 检查反向代理是否放行 WebSocket 协议升级头
- 检查鉴权拦截器是否正确识别用户上下文
- 集群环境检查消息中间件链路

## 5. Tomcat 依赖残留

现象：
- 依赖树出现 `spring-boot-starter-tomcat` 或 `org.apache.tomcat.embed:*`

处理建议：
- 重新执行依赖树命令定位来源
- 优先在业务工程 `pom.xml` 增加针对性排除
- 对公共依赖链路在 BOM 统一管理并排除
