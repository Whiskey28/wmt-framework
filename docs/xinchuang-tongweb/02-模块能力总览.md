# 模块能力总览

## 核心模块

- `wmt-common`
  - 公共工具、通用 DTO、异常与返回模型
  - 适用：所有业务服务

- `wmt-spring-boot-starter-web`
  - 全局异常、统一响应、API 日志、请求包装、XSS 处理
  - 适用：HTTP API 服务

- `wmt-spring-boot-starter-security`
  - 认证鉴权、Token 过滤、权限校验、操作日志
  - 适用：需要用户体系和权限控制的服务

- `wmt-spring-boot-starter-mybatis`
  - 多数据源、MyBatis-Plus、分页与通用数据访问能力
  - 适用：数据库读写服务

## 常用增强模块

- `wmt-spring-boot-starter-redis`：缓存与分布式数据访问
- `wmt-spring-boot-starter-mq`：RocketMQ / RabbitMQ / Kafka 支持
- `wmt-spring-boot-starter-websocket`：长连接与多节点消息推送
- `wmt-spring-boot-starter-job`：定时任务能力
- `wmt-spring-boot-starter-monitor`：监控、链路追踪
- `wmt-spring-boot-starter-protection`：限流、签名、防重放等保护能力

## 业务组件模块

- `wmt-spring-boot-starter-biz-tenant`：多租户上下文与隔离
- `wmt-spring-boot-starter-biz-data-permission`：数据权限规则
- `wmt-spring-boot-starter-biz-ip`：IP 与区域能力

## 推荐依赖组合

- 纯 API 服务：`web + security + mybatis + redis`
- 多租户平台：`web + security + mybatis + redis + biz-tenant + biz-data-permission`
- 实时推送场景：在上述组合基础上加入 `websocket + mq`
