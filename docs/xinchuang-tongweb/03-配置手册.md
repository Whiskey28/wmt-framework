# 配置手册（常用）

以下为业务系统最常用配置项，完整配置请结合各 starter 的 `application.yml` 实际参数。

## 1. Web 与服务基础

```yaml
server:
  port: 8080

spring:
  application:
    name: demo-app
```

## 2. 数据源配置

```yaml
spring:
  datasource:
    dynamic:
      primary: master
      datasource:
        master:
          url: jdbc:mysql://127.0.0.1:3306/demo
          username: root
          password: root
```

## 3. Redis 配置

```yaml
spring:
  data:
    redis:
      host: 127.0.0.1
      port: 6379
      database: 0
```

## 4. 安全配置建议

- 统一由网关或入口层透传用户 Token
- 明确公共路径白名单（健康检查、登录、静态资源）
- 敏感接口务必开启权限注解与操作日志

## 5. 信创容器约束

- 组件库已默认适配 TongWeb，并剥离 Tomcat 传递依赖
- 业务工程不要额外显式引入 `spring-boot-starter-tomcat`
- 每次升级依赖后建议执行一次依赖树核验
